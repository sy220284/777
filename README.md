# 双色球历史数据与模型研究

本仓库用于保存双色球历史开奖数据、模型版本、滚动盲测与奖级评估结果。

## 当前版本

- V3：概率分布覆盖模型（冻结基线）
- V4：号码级概率排序模型（冻结基线）
- V4.2：号码级概率 + 单窗口联合聚类 + 因果门控（冻结基线）
- V4.3：号码级概率 + 多尺度联合关系 + 长窗因果门控（冻结基线）
- **V4.4：V4.3红球 + 蓝球双模型自适应选择（当前生产研究版）**
- 主要评价指标：实际奖级（一至六等奖）、中奖率、投入/固定奖金回报
