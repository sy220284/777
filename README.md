# 双色球历史数据与模型研究

本仓库用于保存双色球历史开奖数据、模型版本、滚动盲测与奖级评估结果。

## 当前版本

- V3：概率分布覆盖模型（冻结基线）
- V4：号码级概率排序模型（冻结基线）
- **V4.2：号码级概率 + 联合概率聚类 + 因果门控（当前生产研究版）**
- 主要评价指标：实际奖级（一至六等奖）、中奖率、投入/固定奖金回报

## V4.2 相对 V4

同一2696期严格滚动盲测：

- 四等奖：5 → **7**
- 五等奖：49 → **57**
- 六等奖：337 → 328
- 未中奖：2305 → 2304
- 固定奖金回报：3175元 → **3610元（+13.7%）**

V4.2的提升主要来自把前12候选池中具有历史联合关系的号码更合理地聚到同一注，并通过滚动置信门控防止随机共现被强制使用。前后各1348期均保持同方向改善。

下一阶段：三元联合概率强收缩、候选池概率校准、动态胆码门控。

> 注意：彩票开奖具有随机性。历史盲测提升不代表未来可以稳定预测或保证中奖，本仓库仅用于统计研究与模型验证。
