# 双色球历史数据与模型研究

本仓库用于保存双色球历史开奖数据、严格滚动盲测、随机对照、概率校准和最终研究版执行链。

当前项目已收口为 **V4.5.1 可预测性信号门控**：模型只有在 V4 前12候选近期覆盖仍达到随机理论基线时，才允许使用 V4.5 高奖集中策略；信号不足时自动回退到 V4.3 分散策略。

> 彩票开奖具有高度随机性。现有历史检验没有证明存在稳定、可重复、高于随机基线的预测能力。本项目是统计研究与复现实验，不保证中奖，也不把偶发高奖解释成稳定预测能力。

## 一、当前数据

- 冻结基础快照：`data/ssq_history_2003_2026-05-03.csv.gz`，3446期。
- 当前增量：`data/increment_current.csv`，56期。
- 当前完整历史：**3502期**，截至 **2026-09-10 / 2026105期**。
- 2026105：红球 `02 04 13 14 15 30`，蓝球 `08`。
- 原 `data/increment_2026050_2026104.csv` 保留不动，用于复现此前55期独立前向段。
- `data/current_manifest.json` 是当前数据状态与完整性校验的唯一清单。

完整性校验同时检查：冻结基础文件 Git blob SHA1、当前增量 SHA256、seq 连续性、期号重复、红蓝球范围和格式。

## 二、直接使用

建议 Python 3.10 或更高版本。

```bash
python -m pip install -r requirements.txt
```

校验当前数据：

```bash
python ssq.py verify
```

生成最终研究版的下一期输出：

```bash
python ssq.py predict
```

默认写入：

```text
predictions/latest.json
```

输出包含：

- V4 红球前12候选；
- V4.5.1 当前总门控状态；
- 自动选择 `V4.5` 或 `V4.3`；
- 两组红球与对应两个蓝球；
- 红球子模型权重、V4.3 两两关系门控、V4.5 集中门控、蓝球融合权重；
- 当前信号均值与随机理论基线。

由冻结基线与当前增量重建完整历史：

```bash
python ssq.py rebuild --out data/history_current.csv
```

## 三、追加新期开奖

先从可靠开奖来源交叉核实，再执行：

```bash
python ssq.py append \
  --issue 2026106 \
  --date 2026-09-13 \
  --red 1 2 3 4 5 6 \
  --blue 7 \
  --verified-against 来源A \
  --verified-against 来源B
```

命令会自动：

1. 校验6个红球不重复、升序且范围为1—33；
2. 校验蓝球范围1—16；
3. 防止重复期号；
4. 追加 `data/increment_current.csv`；
5. 推进 seq、总期数、截止日期和最新期号；
6. 重算当前增量 SHA256；
7. 更新 `data/current_manifest.json`；
8. 重新执行完整数据状态校验。

## 四、最终模型结构

### V4

号码级概率排序基线。红球使用全历史、1000期、500期三个逻辑回归子模型，通过严格时间顺序滚动训练并按近期候选覆盖表现融合。

### V4.3

在 V4 前12候选上加入多尺度两两关系与长窗门控，作为低置信状态下的分散策略。

### V4.5

在高置信状态下允许更集中的两票红球组合，并使用三个蓝球模型的历史奖级效用进行收缩融合。

### V4.5.1

不增加新的号码预测模型，只增加一个总门控：

随机选择12个红球时，每期平均应包含：

`6 × 12 / 33 = 2.181818` 个真实红球。

每期开奖前，只读取此前最近250期 V4 前12候选的真实平均命中：

- `>= 2.181818`：允许使用 V4.5；
- `< 2.181818`：回退 V4.3。

最终下一期执行器：`models/v4_5_1/predictor.py`。

## 六、随机性与概率校准结论

`tools/signal_radar.py` 对 V4 前12候选做2000次时间顺序打乱检验：

- 前12平均命中：`p≈0.2455`；
- 前12含4+：`p≈0.0595`；
- 前12含5+：`p≈0.5355`；
- 前12含6：`p≈0.26`。

概率校准也没有通过：恒定18.18%随机基线的 Brier 分数优于 V4 三个原始概率子模型；按排名或号码偏差进行因果校准虽然能改善概率外观，却不能稳定改善候选池和实际奖级。因此校准只保留作诊断，不接入最终选号链。

## 七、项目原则

- 只增加能解决已验证瓶颈的功能。
- 任何新模块先证明候选池或概率预测存在增益，再看奖级。
- 旧历史用于研究筛选，新增真实开奖的独立前向表现权重更高。
- 不使用当前期开奖结果决定当前期策略，所有门控严格只读取过去数据。
- 没有高于随机基线的证据时自动降低集中程度。
- 不继续围绕已失败的窗口、正则、概率校准参数做无止境挖掘。

至此仓库已经具备：**冻结研究基线、当前数据维护、完整性校验、最终模型入口、因果策略门控、下一期输出与可复现历史验证**。
