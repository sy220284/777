# 双色球历史数据与模型研究

本仓库用于保存双色球历史开奖数据、模型版本、滚动盲测与奖级评估结果。

## 当前版本

- V3：概率分布覆盖模型（冻结基线）
- V4：号码级概率排序模型（冻结基线）
- V4.2：号码级概率 + 单窗口联合聚类 + 因果门控（冻结基线）
- **V4.3：号码级概率 + 多尺度联合关系 + 长窗因果门控（当前生产研究版）**
- 主要评价指标：实际奖级（一至六等奖）、中奖率、投入/固定奖金回报

## V4.3 相对 V4.2

同一2696期严格滚动盲测：

- 四等奖：7 → **8**
- 五等奖：57 → **60**
- 六等奖：328 → 327
- 未中奖：2304 → **2301**
- 固定奖金回报：3610元 → **3835元（+6.23%）**

V4.3保留V4逐号概率排序不动，只升级组合层：500期两两联合关系占80%，600期联合关系占20%，并把聚类置信门控窗口从250期延长到600期。这样减少局部随机共现造成的过度切换。

本轮同时验证并淘汰：三元联合概率、固定/动态胆码、边际概率强聚集。它们均未表现出跨时间段稳定增益，不进入当前生产研究版。详细记录见 `docs/V4_3_EXPLORATION.md`。

当前关键诊断：前12候选池在2696期中有12.43%的期次包含至少4个真实红球，高于随机12号池约10.97%的理论水平。下一阶段重点不是继续堆高阶共现，而是提升号码级概率校准、识别“候选池含4+”状态，并在有足够置信度时再研究动态胆码。

> 注意：彩票开奖具有随机性。历史盲测提升不代表未来可以稳定预测或保证中奖，本仓库仅用于统计研究与模型验证。
