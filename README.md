# 双色球历史数据与模型研究

本仓库用于保存双色球历史开奖数据、模型版本、滚动盲测与奖级评估结果。

## 设计原则

- 任何模型升级以解决当前已验证瓶颈为前提，不为复杂而复杂。
- 优先采用可解释、可复现、计算成本合理的方案；简单方案能够达到同等效果时，不引入额外层级。
- 新增模块必须在独立滚动验证中证明有增量价值，否则不进入主模型。
- 先修号码排序与泛化，再优化高奖级组合；避免同时改多层导致无法判断收益来源。
- 历史回测只用于研究与筛选，新增真实开奖的前向表现权重更高。

## V4.5 相对 V4.4（冻结旧实验口径）

同一2696期严格滚动盲测：

- 一等奖：0 → 0
- 二等奖：0 → 0
- 三等奖：0 → 0
- 四等奖：10 → **13（+30%）**
- 五等奖：59 → 50
- 六等奖：327 → 328
- 未中奖：2300 → 2305
- 5红集中期：1 → **3**

V4.5 的目标不再是最大化普通中奖期率，而是把有限两注预算向更高奖级集中。红球保持 V4 逐号排序与 V4.3 常规分组作为基线；只有高奖集中置信度达到过去800期75%分位以上时，才允许两注最多共享3个红球，使高置信候选尽量集中到同一注。低置信状态自动回退常规分组。

蓝球由 V4.4 的“硬选择一个子模型”升级为三个模型的连续融合：1000期完整特征、750期完整特征、1000期精简频率/趋势/遗漏模型。每一期仅根据此前1100期已经发生的实际奖级效用与前二蓝球覆盖表现计算权重，并做温度缩放和15%等权收缩，避免短期单模型偶然走强后被全部押注。

本阶段同时验证并淘汰：扩大候选池至14/15、两注强制共用同一蓝球、跨蓝球模型分别取第一候选、静态固定蓝球模型、三元联合概率。详细记录见 `docs/V4_5_EXPLORATION.md`。

## 下一阶段

1. 以2026050—2026104这55期独立前向结果为约束，优先修复近期号码排序漂移，而不是继续刷旧历史高奖成绩；
2. 将生产训练更新频率与历史研究分块训练解耦，验证更及时的重训练是否改善真实前向候选池；
3. 只有新信息源能够在独立前向区间显著提高前12候选池含4+/5+真实红球概率时，才允许继续提高集中下注强度；
4. 如能取得开奖设备、球组批次等独立外生信息，单独验证其增量价值，不与历史派生特征混淆。

> 注意：彩票开奖具有随机性。历史盲测提升不代表未来可以稳定预测或保证中奖；尤其本仓库已经经历多轮基于旧历史的模型迭代，因此旧历史成绩存在模型选择偏差，新增独立前向样本的权重应更高。
