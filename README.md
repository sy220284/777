# 双色球历史数据与模型研究

本仓库用于保存双色球历史开奖数据、模型版本、滚动盲测与奖级评估结果。

## 设计原则

- 任何模型升级以解决当前已验证瓶颈为前提，不为复杂而复杂。
- 优先采用可解释、可复现、计算成本合理的方案；简单方案能够达到同等效果时，不引入额外层级。
- 新增模块必须在独立滚动验证中证明有增量价值，否则不进入主模型。
- 先修号码排序与泛化，再优化高奖级组合；避免同时改多层导致无法判断收益来源。
- 历史回测只用于研究与筛选，新增真实开奖的前向表现权重更高。

## V4.6 泛化探索结论

本轮只针对红球排序泛化做最小必要实验，没有同时修改蓝球与高奖组合层。

- 将重训练周期从250期缩短到50期：新增55期前12平均命中由2.055提高到2.200，但全量四等奖由13降到6，固定奖金由4780降到3385元，拒绝直接替换。
- 过去100期快慢模型因果切换：新增55期前12含4+由3期提高到5期，但全量固定奖金降到4705元，奖级没有同步提升，拒绝。
- 保持稳定前12候选池、只做快模型池内重排：整体低于V4.5；旧历史出现过一次孤立二等奖，但新增55期无改善，按过拟合处理。
- 加强逻辑回归正则：旧历史候选池略有改善，但新增55期退化，拒绝。

因此 **V4.5继续保持主版本**。完整实验数据见 `backtests/v4_6/exploration_summary.json`，过程说明见 `docs/V4_6_EXPLORATION.md`。

## 下一阶段

1. 停止继续微调250/50/25期训练周期、切换阈值和正则系数，避免围绕同一历史信息反复过拟合。
2. 优先寻找能够直接提高“前12候选池含5+真实红球概率”的新信息；新特征先验证候选池，再验证实际奖级。
3. 低成本优先补充并验证正式期号、开奖日期等独立时间信息；如无稳定增益则立即淘汰。
4. 如能取得可靠的开奖设备、球组批次等外生元数据，单独建立对照验证，不与现有历史派生信号一起调参。
5. 在红球候选池没有出现新的独立前向增益前，V4.5的高奖集中层和蓝球层保持冻结。

> 注意：彩票开奖具有随机性。历史盲测提升不代表未来可以稳定预测或保证中奖；尤其本仓库已经经历多轮基于旧历史的模型迭代，因此旧历史成绩存在模型选择偏差，新增独立前向样本的权重应更高。
