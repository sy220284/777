# 双色球历史数据与模型研究

本仓库用于保存双色球历史开奖数据、模型版本、滚动盲测与奖级评估结果。

## 当前版本

- V3：概率分布覆盖模型（冻结基线）
- V4：号码级概率排序模型（冻结基线）
- V4.2：号码级概率 + 单窗口联合聚类 + 因果门控（冻结基线）
- V4.3：号码级概率 + 多尺度联合关系 + 长窗因果门控（冻结基线）
- V4.4：V4.3红球 + 蓝球双模型自适应选择（冻结基线）
- **V4.5：高置信红球集中投资组合 + 奖级效用蓝球收缩融合（当前生产研究版）**
- 主要评价指标：实际奖级（一至六等奖）、高奖级集中度、投入/固定奖金回报

## V4.5 相对 V4.4

同一2696期严格滚动盲测：

- 一等奖：0 → 0
- 二等奖：0 → 0
- 三等奖：0 → 0
- 四等奖：10 → **13（+30%）**
- 五等奖：59 → 50
- 六等奖：327 → 328
- 未中奖：2300 → 2305
- 5红集中期：1 → **3**
- 固定奖金回报：4225元 → **4740元（+12.19%）**
- 固定回报率：39.18% → **43.95%**

V4.5 的目标不再是最大化普通中奖期率，而是把有限两注预算向更高奖级集中。红球保持 V4 逐号排序与 V4.3 常规分组作为基线；只有高奖集中置信度达到过去800期75%分位以上时，才允许两注最多共享3个红球，使高置信候选尽量集中到同一注。低置信状态自动回退常规分组。

蓝球由 V4.4 的“硬选择一个子模型”升级为三个模型的连续融合：1000期完整特征、750期完整特征、1000期精简频率/趋势/遗漏模型。每一期仅根据此前1100期已经发生的实际奖级效用与前二蓝球覆盖表现计算权重，并做温度缩放和15%等权收缩，避免短期单模型偶然走强后被全部押注。

### 分段稳定性

前后各1348期固定回报：

- 前半段：1825 → **2035元**，四等奖4 → **5**
- 后半段：2400 → **2705元**，四等奖6 → **8**

四个连续674期固定回报：

- 955 → **1115元**
- 870 → **920元**
- 1260 → **1400元**
- 1140 → **1305元**

四段均未退化。中奖期率略降属于有意用部分低价值覆盖换取高奖级集中，不作为本版本退化判据。

本阶段同时验证并淘汰：扩大候选池至14/15、两注强制共用同一蓝球、跨蓝球模型分别取第一候选、静态固定蓝球模型、三元联合概率。详细记录见 `docs/V4_5_EXPLORATION.md`。

## 下一阶段

1. 冻结 V4.5 参数，用2026-05-03之后新增开奖做真正前向验证；
2. 针对历史上45个“前12候选池含5+真实红球”的高价值状态研究可观测门控，但必须采用稀有事件强收缩和时序留出；
3. 继续研究“主攻票 + 防守票”的非对称组合概率目标，直接优化5红/6红集中，不再追求六等奖数量；
4. 如能取得开奖设备、球组批次等独立外生信息，单独验证其增量价值，不与历史派生特征混淆。

> 注意：彩票开奖具有随机性。V4.5 的历史盲测提升只说明在当前历史样本和评价口径下奖级分布有所上移，并不证明未来能够稳定预测或保证中奖。
