# 777 工具和低频功能收敛：代码审计决定

> 审计基线：main fadd1e5ddb4028f30eeacdaf0decf4a81d8bd54a
> 本次改动集中于一个 PR。不能因为功能低频就删除安全、恢复、诊断能力。

## 逐项判断和取舍

| 候选 | 查证事实 | 最终决策 |
| --- | --- | --- |
| 任务计划 update_plan | plan/state 保存步骤列表，供规划与展示 | 保留步骤语义；调整工具提示 |
| todo_write | todo/state 保存 pending/in_progress/completed 执行进度 | 保留进度权威来源；减少模型重复填充 |
| create_goal / update_goal | goal/state 维护跨轮目标、验收及状态 | 保留独立数据；提示简单任务无需多建目标 |
| subagent | 默认只读、隔离上下文，可并行 | 增加 context_mode=inherit 读上下文选项；始终只读 |
| subagent_fork | 继承父上下文，允许原有权限内的变更 | 保留高级兼容入口；避免用统一入口暗中扩大权限 |
| workflow | 子任务批处理、并行/流水线、逐项验收 | 保留按需工具；不要重复实现执行层 |
| 规划模式 | EventLog 权威恢复、退出审批、只读限制 | 保留明确的用户审批边界，不做自动切换 |
| 聊天风格偏好 | 已基于用户词组做提示和事件诊断，不删除模型答复 | 保留偏好；隐藏低频命中列表，用户点击才展示 |
| Webhook | 只绑定 127.0.0.1，拒绝 LAN | 保留本机能力；移除暗示已提供加密中继的措辞 |
| 用量展示 | 设置页与运行中心共享记录，运行中心有展开详情 | 保留统计，避免合并成不必要的单页 |
| 高级团队、工具目录 | 多代理管理、权限与工具按需发现需要保留 | 不与 #616 功能树、#617 LSP、#618 页面交互重叠实施 |

## 实现与回归约束

1. 新的普通子代理 context_mode 仅 isolated/inherit；默认 isolated，与旧调用一致。
2. inherit 仅限前台、无独立虚拟屏；仍然只读；不能通过新的模型参数绕过权限。
3. 原有 subagent_fork、workflow、后台持久子代理、Plan Mode、todo 和 goal EventLog 保持兼容。
4. 不把未遵循表达偏好解释为模型生成失败；用户可展开查看及清空诊断。
5. Webhook 文案准确告知本机回环限制。
6. 运行单测、静态架构门禁、Android 设备回归；验证完成前不要合并。

## 自评
- 方案 A：删除 todo/goal、fork 和高级功能：改动面过大，损失执行状态和权限边界，否决。
- 方案 B：再包一层统一存储和 Agent Router：额外引入多套适配/迁移，维护成本高，否决。
- 方案 C：保留持久化协议、收敛常用接口和清晰描述、完善真实使用体验：兼容性与收益平衡，采用。
