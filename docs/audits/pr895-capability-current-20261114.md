## 本轮实际代码改动

沿现有 `Work → 项目 Facade → Catalog / Files 工作区` 路径增加原生文件夹迁移，UI 将“只修改项目关联”与“移动真实文件”明确分开。只移动工作区内、无别的项目相互嵌套引用的独占目录；要求目标目录尚未存在、上级目录有效，用户确认的是源路径版本，并在 Work 统一检查前台及后台活跃任务；用同文件系统原子重命名保留文件与 Git 历史。历史会话日志仍保存原路径，Work 文件预览与下载在原位置不存在时按项目归属、持久迁移历史定位；用户重新关联项目、路径被占用或跨会话时不自动跳转。已有工具参数及旧绝对路径仍需遵循原执行边界，因此项目生命周期保持“部分接通”。持久恢复记录解决“文件已移动但项目索引尚未保存”的进程中断；失败时回滚，双方都存在等歧义情况直接报错并保留字节。
