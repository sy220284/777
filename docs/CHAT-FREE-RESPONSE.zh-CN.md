# 聊天人物自由回应改造

状态：自由回应基础已随 #614 合并。本次连续性优化随当前 PR 合并生效；真实模型聊天质量尚未验收。

## 产品目标与边界

切换人物后，回复应由该人物的人设、已有经历和当前聊天背景产生。应用只提供这些资料，不规定人物如何理解问题、处理冲突、关心用户、提问、解释、拒绝或推进关系。

人物主档案由作者填写的性格、语言风格、自身限制、修订与知识范围继续有效。剧情阶段、世界书权限、当前场景和已经发生的事件保持一致。没有新增人物行为向量、反应指纹、范例脚本、风格判别器或按角色改写流程。

## 退出的设计

- 删除统一的 12 维行为模式、关键问题的高分析模式和共享决策提示。
- 退出按关键词切换人物反应或分析视角的逻辑；普通关系问题与分析类提问均由当前人物根据已有背景自然回应。`/reply`、`/回复建议` 的回复草稿指令保留。
- 移除全角色强制心声、统一安慰/亲近/冲突策略、姿态冷却与重复动作换节拍要求。
- 移除应用内置的助手用语黑名单及按句长、问句数等改写正常人物回复的路径。用户或人物作者自行填写的表达偏好在生成前提供给模型，完成后只记录未遵循情况，不删除台词。
- 退出情绪与未完事项按固定轮数过期、按设备时钟生成日常活动、按观测次数重写人物性格的机制。状态由实际互动更新，共同经历作为事件记录。
- 人物行为设置界面收敛为模型采样设置。采样能力和模型供应商限制沿用原有适配层。

## 当前生成路径

人物稳定资料与作者修订 → 当前场景、人物实际状态、共同经历、可见世界书 → 模型生成。

普通闲聊也携带性格、价值、语言、偏好等稳定资料。原模式与决策提示退出后，其预算归还人物资料；16 类人物资料均作为投影候选，按预算选择完整事实段落，避免平均截取栏目而损坏语言、关键经历与知识范围的原意。相关经历与事实仍按场景补充。

身份或场景连续性检查只用于纠正脱离人设与聊天背景。群聊保留成员身份、公共/私人背景隔离与沉默标记协议，不要求被点名的人物一定发言。用户回复建议属于用户主动请求的草稿能力。

## 兼容与验证

旧人物卡、故事与调参数据仍可解码；旧行为轴、性格权重、冷却和过期计数退出生成控制。温度设置继续生效。人物切换、故事恢复、世界书与私人记忆隔离沿用现有归属机制。

回归覆盖普通闲聊资料可见性、21 个预设、剧情阶段回退、旧调参不影响上下文、未完事件保留、实际事件更新、回复原文保留，以及采样保存失败和等待反馈。确定性测试验证资料与生产路径，不能证明模型实际呈现不同人物。

体验验收需要使用同一模型、相同聊天背景和相同用户话题进行跨人物对照，并加入多轮聊天、角色切换与恢复。评审看是否符合人物、是否像同一个人在说话、背景是否连续；不把问句率、句长、动作或某种反应顺序设成角色必须满足的指标。

### 状态来源的解释

`stateObservations` 是当前状态变化的来源记录，不是新的心理事实源。模型可在 `stateEvidence` 提供原文；实际匹配才标为原文表达，否则记录本轮对话语境并标为归纳。引文只能证明来源，不能证明人物对用户的理解客观正确。字段结束也记录来源，避免只记录冲突而漏掉和解。旧故事无需重写，缺省解码为空，之后的实际对话逐步补充；来源 ID 仅在匹配真实待处理回合时填写。

### 退出与验证边界

删除已失去消费者的流式删词实现及专属测试；原架构门禁退出该已退役符号的存在性要求，所有权与模型请求边界检查继续保留。新增验证覆盖预算再分配、短句接话、和解后的情绪/矛盾清除、状态来源恢复、虚构引文降为归纳、虚拟人物身份以及表达偏好命中时原文保留。

本轮改善了资料覆盖与连续对话检索，不宣称已经具备语义向量检索或模型微调。真实模型跨人物盲测、长聊体验、延迟与费用仍需独立实测；工程回归不代表人物体验已经验收。

## 故事、长聊、群聊与纠错的连续性优化

独立新故事创建自己的经历身份，人物主档案仍共用，关系事件、私人约定、冲突、日记与长期关系事实仅在该故事内延续。继续同一故事、继续当前聊天保留经历身份并登记新会话来源。新群聊仅用人物设定创建成员状态，继续同一个群聊保留自身状态；不默认读取其他故事或群聊的最后状态。老数据按实际来源会话归入原故事，没有明确来源的旧经历不会自动进入独立新故事。日记管理仍可查看各故事的记录。

请求时长聊压缩及图集故事承接均保留双方的真实表达，包括人物承诺、拒绝与后来修改；近期原文、当前有效事实及决定优先。原始日志继续完整保存，有界检查点仍会遗漏更早细节，不能据此承诺无限记忆。

群聊普通接话延续最近实际发言的人物，点名切换对象、集体发言仍保持原入口与调用预算；空回复不更新交流对象。模型仍可沉默，路由不规定任何人物反应。

用户纠正或停用日记后，原对话保留，相关派生状态和连续性依据撤回。新后台写入不能用相同来源重新生成已纠正的日记；生成前、后台归并和会话恢复均从同一日记决定投影，分支切换和回滚后也会遵循纠正。来源不明的旧状态只在与旧记录完全相同时撤回，不把所有情绪一并清空。纠正入口沿用日记编辑，保存说明同步更新。

日记允许事件独立存在，心理记录可留空；有原始人物表达才注明引句，其余心理归纳明确标为待确认推测。可选检索线索由原有后台整理产生，提供事件同义提法和主题，不新增生成调用或人物策略。普通召回退出固定一条限制，仍按相关性、经历归属、有效版本和上下文预算选择完整条目。该方案改善表述变化时的召回，尚未实现向量检索。

人物稳定资料按完整事实段落装入预算，退出各栏目平均截取前缀；放不下的完整条目留在主档案，可按话题补充。相关事实与日记也尽量完整装入，不把半个因果句作为既定经历。超长单条仍受模型上下文预算限制，当前实现不会自动概括或改写作者资料。

导入导出保留故事与日记的经历对应，同时去掉来源会话身份。旧文件缺少经历字段仍可读取，有可核对的故事来源时恢复归属。独立新故事不会默认继承导入的共同经历，已有故事可继续。

验证覆盖独立故事隔离、旧来源迁移、继续会话、群聊交流对象、新群不继承、双方承诺、事件单独记录、不同提法召回、纠错恢复与迟到写入，以及完整资料预算。真实模型长聊与群聊自然程度仍需实聊验收。
