# UI 效果图归档

本目录统一记录 Android 客户端可用于设计复盘、回归比对和发布说明的界面效果图，避免图片散落在 PR、聊天或本地目录后失去上下文。

## 当前归档

| 文件 | 用途 |
|---|---|
| `docs/images/home.png` | 首页 / 会话主界面基准 |
| `docs/images/chat.png` | 聊天内容区基准 |
| `docs/images/session-info.png` | 会话信息与详情界面 |
| `docs/images/subagent.png` | 子智能体界面 |
| `docs/images/trajectory.png` | 执行轨迹界面 |
| `docs/images/banner.jpg` | 项目展示横幅 |

## 归档规则

1. 只提交用于设计验收、功能说明或稳定回归的截图；临时调试图不入库。
2. 同一界面的新版截图覆盖旧基准前，必须确认旧图对应行为已经废弃；需要保留历史时使用日期后缀。
3. 文件名使用小写短横线，优先表达页面或功能，例如 `tasks-chat.png`、`persona-gallery.png`。
4. 截图不得包含真实密钥、账号、通知正文、私人对话、文件路径等敏感信息。
5. UI 改动若改变主要结构、导航或关键状态，应同步更新对应效果图与本清单。
6. 自动截图与协议抓取工具说明见 `tools/capture/README.md`。

这些图在对应界面发生实质视觉变更时再补，不为凑数量生成无意义截图。
