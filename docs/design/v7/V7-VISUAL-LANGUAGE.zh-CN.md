# 神言 V7 · 视觉语言规范（设计目标，待实施）

> **性质：新一轮视觉设计目标，不等同于已上线实现。** 现行生产事实仍以 [V6.3 当前实现](../v6/V6-CURRENT-IMPLEMENTATION.zh-CN.md) 与 Compose 源码为准；本文定义 V7 视觉语言，落地方案与进度见 [STATUS.zh-CN.md](STATUS.zh-CN.md)。
> **范围：** Android 原生手机界面、三主题、表面层级、排版、控件、动效、壁纸、无障碍与性能；**不改变**七条业务主路由（`HOME / PERSONA_GALLERY / DIARY / WORKSPACE / TASKS / TOOLS / SETTINGS`）、**不删除** 21 项设置入口、**不恢复**已退役入口、**不改**任何业务契约。
> **机读令牌：** [tokens.json](tokens.json)（三主题色板 + 字号 + 几何 + 动效，供实现与 CI 校验共用）。

## 1. V7 主张

V6 是「暖墨 · 精密玻璃」：多层半透明材质 + 壁纸分区取色 + 实时模糊 + 光影细节。V7 推翻的是**表达方式**，不是功能。

| # | 主张 | 含义 | 相对 V6 的变化 |
|---|---|---|---|
| 1 | **一层纸面** | 层级优先由排版、留白与分隔线表达；透明材质只留给真正浮在内容之上的东西 | L2/L3 默认不透明，取消实时模糊；L4 才允许背景模糊 |
| 2 | **排版即层级** | 字号、字重、留白三者承担区分，描边/底板/阴影/光晕不再叠加成四重强调 | 每处交互最多两种强调手段 |
| 3 | **一盏灯** | 全局只有一套主强调色，八色卡降级为"个性化选择"而非八套并列色板 | 八色卡统一由求解器产出前景色与按下态 |
| 4 | **读得下去** | 正文优先：行距、字重对比、中英混排、放大字体、代码与引用 | 正文 16sp/1.65，代码等宽 14sp，弱化装饰字号 |
| 5 | **动作有轻重** | 主动作实心、次动作描边、轻动作纯文字，三者不混用 | 行内操作不再一律加底板 |

**不可协商的红线：** 功能不删、入口不增、行为不变、性能不退化、对比不妥协。视觉重做不得成为任何能力被顺手改掉的借口。

### 2.3 墙面/壁纸的处理

V7 保留动态壁纸与壁纸取色能力，但改变默认表达：

- **默认不再"透过玻璃看壁纸"**：卡片、栏位改为不透明纸面，壁纸只在画布与浮层背后可见。
- 壁纸作为背景层保留用户设定的取色与遮罩强度；任何放在壁纸上的正文，必须在**最终合成像素**上满足 2.2 的门槛，不满足时该区域自动升级为 `solid` 兜底。
- 外观设置里的"透明度"滑块在 V7 中明确改名为**"壁纸可见度"**，并显示真实生效范围（受安全下限约束时说明原因），避免用户拖到底却什么都没变。

### 3.2 前景与按下态求解规则（替代 V6 的固定 `onPrimary`）

```
onAccent = argmax over { #FFFFFF, #1A1613 } of contrastRatio(候选, accent)
accentPressed = accent 向明度反方向移动 8%（浅色底压深，深色底提亮，保持色相）
```

- 禁止"所有浅色卡都用白字"这类固定配对；白字与黑字由实测对比度决定。
- 求解必须在**按下态填充色**上复算一次，两态都 ≥4.5:1 才允许使用该卡。
- 文字型图标（如发送 / 停止）取同一求解结果，不得无条件写死白色。

## 4. 表面与层级语法

V6 的 L1–L5 保留编号，但职责重写，且**默认更实**：

| 层级 | V7 语义 | 不透明度 | 模糊 | 阴影 | 边 |
|---|---|---|---|---|---|
| L0 画布 | 页面底色 / 壁纸层 | 不透明 | 无 | 无 | 无 |
| L1 分区 | 内容分组、留白 | 不透明（=canvas） | 无 | 无 | 仅用 `rule` 分隔线 |
| L2 栏 | 顶栏、输入承载、工具条 | 不透明 `bar` | 无 | 无 | 底边 1px `rule` |
| L3 卡片 | 需要聚合的信息卡 | 不透明 `surface` | 无 | 无 | 1px `rule`（可选 0.5 强度） |
| L4 浮层 | 菜单、Sheet、Dialog、文件预览 | `overlay` 92% + 背景模糊 20dp | 20dp | 菜单 6dp / Sheet 10dp / Dialog 14dp | 1px `ruleStrong` + 顶部高光线 |
| L5 实心 | 复杂嵌套、降透明、高对比兜底 | 不透明 `solid` | 无 | 无 | 1px `rule` |

**关键变化：**

1. **取消 L2/L3 的实时背景模糊。** V6 的 L2 栏 24dp、L4 浮层 32dp 模糊改为只有 L4 保留 20dp；低端机与省电场景直接降级为 `solid`，文字层级不变。
2. **取消多层半透明叠加。** V6 用 alpha 递增表达深度，V7 用**不透明 + 明度差**表达深度；`accentSoft` 只用于选中行，不做玻璃底。
3. **L4 拆出三种语义外观**（不是新增层级）：`menu` / `sheet` / `dialog`，共用色板与边线，阴影、圆角、阅读密度不同。
4. **嵌套上限降为 2 层。** 出现第三层时改用 L5 或间距分隔，禁止三层半透明叠放。

**规则：**

- 中文正文不使用 `textSecondary` 承担正文职责；`ink2` 只用于辅助说明，`ink3` 只用于时间戳与元信息。
- 中英混排：数字、路径、ID 一律用 `mono` 或带等宽回退，避免基线漂移。
- 放大字体到 200% 时，行高按倍数放大；按钮与行高改为**纵排自适应**（沿用 V6 已实现的大字设置行），不截断、不省略号隐藏含义。
- 对比度与字号门槛：正文 ≥4.5:1；`display/title` ≥3:1（仍以 4.5 为目标）。

## 7. 组件语法

### 7.1 按钮三级（互不混用）

| 级别 | 表现 | 使用场景 |
|---|---|---|
| 主要 | 实心 `accent` + `onAccent` | 每屏最多一个明确主动作 |
| 次要 | 1px `ruleStrong` 描边 + `ink` | 并列动作、取消 |
| 轻 | 纯文字 `accent`（无底板） | 行内动作、链接、展开 |

- 行内操作不再给每个动作加底板；一屏内同级动作并排时用分隔线或 6dp 间距区分。
- 禁用态：`ink3` 文字 + 无底板，不靠降低 alpha 伪装。
- 图标按钮维持 48dp 命中区，视觉尺寸 24dp。

### 7.2 聊天与工作（HOME）

- **助手回复**：全宽开放阅读，无卡片、无底板；段落间距 12dp；列表、引用、代码块、表格各有独立排版。
- **用户气泡**：右下对齐浅染底（`accentSoft`），圆角 16dp，最大宽度 78%，纯文字无图标装饰。
- **元信息**：时间戳、模型、耗时使用 `caption` + `ink3`，放在气泡外侧，不进入气泡内部。
- **操作区**：回复下方一行轻量动作（复制 / 重试 / 分支 / 更多），全部为纯文字或 24dp 图标；不再默认展开成卡片。
- **Work 时间线**：改为「左侧 2dp 状态轨 + 右侧内容」结构。当前步骤用 `accent` 轨点 + `bodyStrong` 标题；已完成步骤降为 `ink3` + 一行摘要；失败步骤用 `danger` 图标 + 文案（不靠颜色单独表达）。
- **成果卡**：改为「文件样式」——图标 + 文件名 + 大小/类型 + 操作行，去掉厚重容器。

### 7.3 列表与设置

- **列表行**：图标（24）+ 主文案（`bodyStrong`）+ 辅助说明（`bodyQuiet`/`ink2`）+ 右侧状态或箭头；行高 56dp 起步，可换行不截断。
- **设置分组**：分组标题 `heading` + 行列表；行之间用 `rule` 分隔线，不再"卡片套卡片"。
- **开关/单选**：跟随行文案的基线，不做独立彩色药丸。
- **危险操作**：文字用 `danger`，位置放在分组末尾，不加红底。

### 7.4 空态

- 单一插画（沿用 V6 11 枚独立资源图标）+ 标题 `title` + 一句说明 `bodyQuiet` + 可选主动作。
- 不使用插画背景色块，不使用渐变。

### 7.5 浮层

| 变体 | 圆角 | 阴影 | 内边距 | 密度 |
|---|---|---|---|---|
| `menu` | 16dp | 6dp | 12/16dp | 紧凑，单列 |
| `sheet` | 20dp | 10dp | 16/20dp | 中等，允许标题栏 |
| `dialog` | 16dp | 14dp | 20/24dp | 宽松，正文优先 |

- 浮层背景使用 `overlay` + 背景模糊；系统"减少透明度"开启时退化为 `solid`，**不得出现白底**。
- 菜单项高度 ≥48dp，文案不省略号截断。

## 8. 动效

沿用 `SyMotion` 作为唯一入口，时长收敛为更利落的一组：

| 事件 | V7 | V6 |
|---|---|---|
| 按压 | 60ms | 70ms |
| 选中 | 140ms | 150ms |
| 页面推入 / 弹出 | 240 / 200ms | 260 / 220ms |
| Sheet | 240ms | 280ms |
| Dialog | 200ms | 220ms |
| 侧栏 | 160ms | 180ms |
| 内容淡入 | 110ms | 130ms |
| 进度 / 状态过渡 | 260ms | 280ms |

- 缓动统一 `CubicBezierEasing(.22f, 1f, .36f, 1f)`，不新增第二套曲线。
- 按压缩放从 `.985` 收到 `.99`（更轻）。
- 系统"减少动效"时全部非必要时长归零，状态语义与可操作性保留。
- 持续动效只允许出现在**真实运行状态**上（Work 步骤、插件安装、任务执行）；不得模拟进度百分比。

## 9. 壁纸与区域取色

- **采样位置唯一**：文字框、Chip、卡片等控件与材质容器使用**同一屏幕坐标**采样，不再"固定取中段"。
- **分区规则**：沿用三段（顶部 30% / 中部 30%→74% / 底部）划分，但每段取该段**明暗极值**（不只取均值），以最不利像素计算对比度。
- **最终合成校验**：文字最终像素 = 文字色合成到"控件实际所在区域的最终背景"上再计算对比度；不达标时该控件升级到 `solid` 底，而不是降低文字对比度。
- **透明度安全下限**：用户设想的透明度先经安全下限修正，滑块显示真实生效范围；若被修正，外观设置给出明确说明。
- **降级链**：`overlay + blur` → `overlay 实色` → `solid`，任何一级都必须保证正文 ≥4.5:1。

## 11. 无障碍与性能预算

- 对比度：见 2.2；文字 ≥4.5:1，大字与非文字图形 ≥3:1。
- 触达：所有可交互目标 ≥48dp；TalkBack 顺序与视觉顺序一致；状态必须同时有文字（如"等待批准"），不能只靠颜色。
- 放大字体：200% 下正文、设置行、按钮、对话气泡不得截断或重叠。
- 窄屏：320dp 与 360dp 必须可用；图标行可换行，选项条横向滚动。
- 性能：V7 取消 L2/L3 实时模糊，单帧绘制调用与模糊层数量显著下降；滚动中不新增每帧布局计算。
- 透明与模糊总预算：同屏最多 1 个 L4 浮层带模糊；列表项不得自带模糊层。
