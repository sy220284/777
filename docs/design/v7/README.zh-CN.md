# 777 V7 · 墨白工作室

基于 `main@5fbfb372` 的手机端重新设计。采用上传的《UI设计专项导演 V6.3.2》和 ui-ux-pro-max：前者决定任务、构图、状态和视觉交付，后者补充对比度、48dp 触控、动效降级、焦点与 Compose 状态规范。风格选择由本次设计提出，尚无用户对具体颜色的确认。

## 产品结构与真实运行逻辑

| 场景 / Owner | 主要链路 | 界面信息与返回规则 |
| --- | --- | --- |
| 首页 / SHELL | 启动恢复 → 路由 → CHAT / WORK 的 Feature 投影 | 模式开关、抽屉、当前会话；不创建第二个运行状态 |
| 聊天 / CHAT | 选择人物或群聊 → 草稿/附件 → 模型与思考档位 → 流式回复 → 会话、关系与记忆 | 阅读优先，保留人物上下文、群聊发言人、停止、重试、回复建议、历史分页 |
| 人物图集 / CHAT | 预设/导入/新建 → 编辑资料与肖像 → 精确保存人物/故事 → 进入对应会话 | 图片主导、资料和故事次级；编辑未保存状态、排序、置顶、多选和删除仍保留 |
| 人物日记 / CHAT | 人物选择 → 日期与记录 → 查看/生成 → 持久化结果 | 文学式日期与正文；空记录、加载、失败与生成中分别呈现 |
| 工作 / WORK | 请求/附件/计划/团队 → Agent 执行 → 工具/审批/提问 → 成果版本与工作记录 | 任务状态、步骤、等待用户与交付文件优先；运行中区分干预当前执行与排队下一轮 |
| 工作区 / WORK | 项目/任务/成果/其他文件 → 路径浏览 → 预览/编辑/分享 → 写入回执 → 刷新 | 文件行与路径导航；多选不被刷新清空；项目、代码审查、下载和导入仍在更多菜单 |
| 自动化 / AUTOMATION | 新建/对话创建 → 时间/触发配置 → 受理 → 后台执行 → 会话/结果 | 以时间和真实状态组织；暂停/恢复/取消/立即运行展示处理中与拒绝，禁止虚假进度 |
| 能力中心 / TOOLS | 插件/技能/连接目录 → 详情 → 安装/授权 → 注册/发现 → 实际健康状态 | 三种能力清晰分层；浏览器授权不等于连接成功；详情、权限、诊断和来源回执可查 |
| 设置 / SETTINGS | 搜索/分组 → 模型/账户/外观/记忆/权限等配置 → 对应 Owner 提交 → 回执 | 表单与配置行；搜索定位、返回保留、凭据私有性和首次启动准备状态沿用当前主线 |

共享的 Session、Model、Agent、Tool、Memory、Resource、Usage、Event 继续持有运行事实。UI 只消费 Feature API / projection。七个稳定路由不变；设置的全部二级入口保持原有导航图，媒体生成、模型性能、用量、定价、记忆管理、通知、诊断、存储和账户仍通过原入口进入。

## 视觉方案

比较过三个方向：延续暖色玻璃容易接近旧版；高饱和科技霓虹增加长文阅读负担；选择**墨白工作室**，以内容组织形成场景差异。浅色画布 `#F5F7F3`、纸白 `#FFFFFF`、墨色 `#202923`、苔绿 `#315447`；柠黄 `#DDEBA4` 只用于低面积选中提示。深色独立配置为石墨绿，保留纯黑模式。历史显式配色继续可选，旧“流体杏”不会被静默改写。

正文 16sp / 27sp，工作正文 16sp / 27sp；大标题 28sp / 36sp，导航与设置 16sp。中文保持系统回退和现有字库，代码保留等宽体。4/8/12/16/24/32 的间距节奏；控件圆角 16，阅读卡 20，弹层 28，按钮 48dp。默认实体阅读表面，壁纸与透明度设置仍有实际效果。

- 聊天：大面积开放正文，用户气泡右上小切角，输入区作为唯一主要操作台。
- 工作：收敛顶部状态、步骤与交付入口，运行卡和正文分工；不使用虚构的百分比。
- 人物：肖像和名字形成封面，资料、故事、关系分层；人物图片复用仓库预设资源。
- 文件：路径、文件类型、名称与操作形成稳定行，不把每个文件变成营销卡片。
- 日记：日期和阅读正文构成时间感，减少重复背景。
- 自动化：状态与下一次执行时间组成时间线，动作进入详情。
- 能力：安装、授权、注册、发现和健康分别标注，详情为完整页面。
- 设置：分组标题与行分隔建立秩序，搜索保持可见。

## 抽屉、弹层和运动

抽屉采用有独立阅读底色的工作台：个人入口、新会话、当前模式入口、历史分组、全局设置。手机保留模态抽屉和边缘返回。长内容使用可滚动完整页面；短决策/参数用底部弹层；危险操作保留显式确认。弹层有拖动柄、标题、关闭/取消、键盘避让，48dp 操作目标。

按压 90ms，选择 140ms，页推入 220ms / 退出 180ms，弹层 240ms，抽屉 220ms；页面位移 12dp，平级 4dp。只移动被操作对象，不做整页持续漂浮。复用唯一 SyMotion 和系统减少动画入口；减少动画时取消空间变换，状态与取消不依赖动画结束。加载只反映真实运行，不装饰为完成。

## 交付与验证边界

`mobile/index.html` 是可离线打开的交互设计预览，内含聊天、工作、人物、日记、文件、自动化、能力、设置、抽屉与弹层，以及深色/短屏/大字/异常模式。**示例数据仅用于设计，不代表设备运行事实。** Android 实现沿用原路由和回调，实际实现范围与验证结果见提交说明；原型截图不能作为 Android 真机验收。

执行顺序：梳理路由与状态 → 交互预览 → 共用令牌与原生控件 → 逐场景接入 → 静态边界和浏览器交互检查 → 提交与远端验证。按用户要求不使用子代理、不进行本地编译或构建。
