# 神言 V6.3 · 完整设计包交付变更

## 版本

- **交付版**：V6.3；该版本标识覆盖设计规范、手机离线 HTML、图标 SVG、生产 Compose/XML、机器清单和 ZIP 构建入口。UI 3.0 跨包架构另依权威规范，不等于此设计包发布。
- **候选 PR**：#715。源文件经过 CI 后方可合并。直到 PR 合并，不能宣称全部新版图标已进入 Android 主线。
- **页面场景**：现行 7 条路由、21 个设置目的地，三主题；**不使用历史 38 屏截图**。
- **素材实物**：128 个可编辑图标变体 = 24 个现行功能入口 + 61 个通用操作 + 20 个文件类型明暗图标 + 11 个独立按钮/空态资源 + 12 个历史重绘。品牌 Logo、通知栏蝴蝶和透明启动占位是单独的身份/系统例外。
- **统一规范**：24dp 图形网格、1.75px 标准描边、圆端点与圆连接；最小触控 48dp；文件类 40dp；空态插画保持 100dp，不应强行缩成操作按钮。
- **真实改动**：`SyEntryIcons.kt` 24 枚、`FeatherIcons.kt` 61 枚、`ShenyanBasics.kt` 搜索图标、31 个 Android `drawable` XML、对应 SVG/manifest、设置返回、弹层焦点、按钮尺寸及过期文案。
- **验证**：`python3 docs/design/v6/audit-all-icons.py` 逐路径比对 Kotlin/XML 和 SVG；`build-standalone.py --check` 比对原型源码/输出；`sync-design-package.py` 打包当前设计源并校验 SHA/CRC。正式 Android 编译和真机视觉以最新 PR/设备结果为准。
- **不承诺范围**：离线浏览器是投影，不能替代 Android 壁纸区域模糊、复杂输入法、TalkBack 或 Figma 可编辑组件验收；Figma Starter MCP 限额阻塞时不宣称已在线同步。
