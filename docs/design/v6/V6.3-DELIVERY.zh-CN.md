# 神言 V6.3 · 完整设计包交付变更

## 版本

- **交付版**：V6.3；该版本标识覆盖设计规范、手机离线 HTML、图标 SVG、生产 Compose/XML、机器清单和 ZIP 构建入口。UI 3.0 跨包架构不属于 V6.3 原生设计包，现已进入回退清理范围。
- **历史合并记录**：[PR #715](https://github.com/sy220284/777/pull/715) 已于 2026-10-14 合并，V6.3 图标设计源有正式历史基线；当前恢复版本需以 [PR #766](https://github.com/sy220284/777/pull/766) 的最新构建与设备验收为准。
- **页面场景**：现行 7 条路由、21 个设置目的地，三主题；**不使用历史 38 屏截图**。
- **素材实物**：128 个可编辑图标变体 = 24 个现行功能入口 + 61 个通用操作 + 20 个文件类型明暗图标 + 11 个独立按钮/空态资源 + 12 个历史重绘。品牌 Logo、通知栏蝴蝶和透明启动占位是单独的身份/系统例外。
- **统一规范**：24dp 图形网格、1.75px 标准描边、圆端点与圆连接；最小触控 48dp；文件类 40dp；空态插画保持 100dp，不应强行缩成操作按钮。
- **真实改动**：`SyEntryIcons.kt` 24 枚、`FeatherIcons.kt` 61 枚、`ShenyanBasics.kt` 搜索图标、31 个 Android `drawable` XML、对应 SVG/manifest、设置返回、弹层焦点、按钮尺寸及过期文案。
- **验证**：`python3 docs/design/v6/audit-all-icons.py` 逐路径比对 Kotlin/XML 和 SVG；`build-standalone.py --check` 比对原型源码/输出；`sync-design-package.py` 打包当前设计源并校验 SHA/CRC。正式 Android 编译和真机视觉以最新 PR/设备结果为准。
- **不承诺范围**：离线浏览器是投影，不能替代 Android 壁纸区域模糊、复杂输入法、TalkBack 或 Figma 可编辑组件验收；Figma Starter MCP 限额阻塞时不宣称已在线同步。

## V6 恢复与新增功能验收边界（PR #766）

- V6 消息卡片与文档抽屉共用同一个交互文档业务端口和同一份会话草稿，不再维护两套 UI 3.0 中间状态。
- 交互文档生成、表单修改、编辑与删除继续经过当前 Session / Work 的身份、修订及权限校验；额外模型调用和删除必须经用户确认。
- UI 改造期间新增的 GitHub 仓库只读浏览、会话 ZIP 恢复等能力应出现在 V6 原生页面，不通过恢复朝夕视觉包提供。
- 功能源码索引由 `.github/workflows/v6-feature-index-refresh.yml` 根据真实生产代码重建；索引重建通过不等于设备交互验收通过。
- 本次恢复在 PR #766 仍为 Draft 期间不得宣称已合并或已发布，最终验收必须对应同一个最新提交 SHA 的完整 CI、Android 16/17 与功能入口核查。
