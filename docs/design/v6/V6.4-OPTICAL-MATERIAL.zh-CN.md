# 神言 V6.4 · V6.3 液态玻璃光学升级规范与验收

> **状态：候选设计与实现增量，待 PR 合并。** 基于 V6.3 的 7 路由、21 设置目的地、128 图标变体、三主题和当前 Compose；不是另一套 UI 包，也不恢复在 #718/#719 中移除的大面积底板。
>
> **权威顺序**：业务和跨 UI 接口继续遵守 [UI 3.0](../UI-3.0.zh-CN.md)，V6.3 负责入口/图标/布局；本文件新增光学材质目标与验收要求。以**真实 Android 渲染证据**判定视觉是否达标；不能以代码等于旧文档、静态概念图或 Figma 原生节点名称代替。

## 1. 目标和准确术语

V6.3 的 L1–L5 只是叠色、模糊、阴影和透明度等级。V6.4 将“开放式连续背景”“毛玻璃”“有折射的光学玻璃”“实色风险确认”分为四种语义，禁止把普通透明列表冒充玻璃，也禁止全局给 53 个旧卡片重新铺厚底板。

| 语义 | 适用 | 处理 |
|---|---|---|
| `SCENE` 连续背景 | 页面、设置列表、侧栏、普通大面积区域 | 同一根场景坐标绘制，不模糊、不折射、不叠白色板 |
| `FROSTED` 毛玻璃 | 需要可读性保护的内容承载 | 只处理**对齐后的背景图层**，前景文字永不模糊 |
| `OPTICAL` 小面积光学玻璃 | 菜单、浮动操作、轻型栏、有限面积弹层 | 在 FROSTED 基础上增加可验证的背景像素采样位移、边缘光泽；避免堆叠 |
| `SOLID` 实色安全层 | 哑光主题、降低透明度、权限/破坏性确认 | 不渲染折射、不强制透明，优先对比与风险识别 |

“真实折射”的范围要如实标注：**本轮 Android 13+ AGSL 只重采样自身对齐的场景背景（壁纸/环境光场），不是系统全屏截屏，也不能折射先前绘制的任意聊天文字、View 或另一弹层**。后者需要未来独立的背景纹理宿主与纹理同步机制，必须经隔离测试后才能命名为全面动态折射。

## 2. 统一光学参数（Android 像素变换须考虑 Density）

| 参数 | 本轮候选值 | 作用和约束 |
|---|---|---|
| 场景对齐 | 根画布统一窗口坐标 | 所有玻璃内的纹理与原背景位置一致 |
| 模糊半径 | 继承 V6.3 `18 / 28 / 20 / 32 / 0 dp` | L1–L5；不模糊前景文字/图标 |
| 折射位移上限 | `2.4dp` | 只在边缘一定距离内对背景取样，禁止整幅图滑动 |
| 折射过渡带 | `16dp` | 距离边界用 smoothstep 平滑收敛，中心位移≈0 |
| 高光 | 顶部单层 `1dp` 亮边 | 不参与尺寸测量，不制造第二块实色板 |
| 光学区域限制 | `≤ 1,300,000 px²`，且非实色材质 | 防止整片抽屉和高分辨率大页面持续离屏运算 |
| 平台门槛 | Android API 33+ | AGSL `RuntimeShader` + `RenderEffect`；低版本保持既有模糊 |
| 可访问性 | 系统降低透明度/哑光主题优先 | 不运行折射，保证对比和可辨别的危险语义 |
| 动效 | 不新增持续无意义动画 | 交互继续用 `SyMotion`，遵守减少动画和用户节奏 |

这些值**是新定义的候选设计 Token，不是 Apple/iOS 系统参数的移植或物理精确折射**；可根据真机基准测试优化，但不能由页面自行散落常量。今后应将新增光学参数汇总到统一 MaterialPolicy，业务调用仅表达材质意图。

## 3. 唯一实现责任与约束

- Android：`components/SyOpticalBackdrop.kt` 保持 AGSL shader、能力判断与平台降级；`ShenyanMaterial.kt` 负责对齐、独立模糊层、叠色、光学层、rim 和无障碍；`ShenyanMaterialColor.kt` 保持透明度/对比计算。禁止屏幕自己创建另一套 RenderEffect。
- `SyMaterialSurface` 的 L2/L4 小面积承载可启用 `opticalGlass`；`SySceneBackgroundSurface(opticalGlass = true)` 只在**明确的紧凑浮层**启用，抽屉/页面仍只画连续场景。
- `SyPopupMenu` 的连续背景开启光学边缘；普通底部工作面板保持克制，只有明确为 `floating` 的宽屏浮层申请光学渲染；审批/删除等风险确认保留原有可读层。
- Browser：`mobile/v6.css` 的 `backdrop-filter` 是离线预览的真实浏览器模糊，但不能模拟 Android 的 AGSL edge displacement；`mobile/app.html` 必须由同源 CSS 生成，严禁“浏览器展示=Android 光学达标”的结论。
- Figma：材质节点应分离 `Scene / Blur / Optical Rim / Content / Accessibility Fallback`，分别绑变量、主题和状态，不把效果烘焙成图片；保留 V6.3 SVG 图标和既有组件 ID。**在线画板本轮因 Starter MCP 限额未修改，尚待 Figma 变量及节点同步**。

## 4. 组件策略：防止回退到白底卡片海

| 区域 | 目标 | 明确禁止 |
|---|---|---|
| 普通设置入口/任务/人物行 | SCENE + 文字 + 分隔线 + 选中反馈 | 重新套 L3/L4 整行玻璃牌 |
| 聊天输入栏/胶囊状悬浮控制 | 小面积 FROSTED 或 OPTICAL，优先真实点击体验 | 覆盖文本的 blur、厚边框、静态大面积阴影 |
| 三点菜单/加号栏/轻型 popover | 连续场景 + 轻微边缘折射与高光 | 菜单背后显示聊天文字、弹出白块 |
| 较大底部 Sheet | 连续场景或 FROSTED，按可读性选取 | 强制整个高面板做昂贵光学通道 |
| 审批/删除/敏感操作 | SOLID / 对比确认 | 仅凭透明高光区分危险操作 |
| 消耗图表/媒体内容 | 内容真实数据和媒体本身优先 | 为显示玻璃而改变图表、遮挡媒体 |

## 5. 验收矩阵：必须基于真实像素与性能

1. **背景对齐**：几何纹理壁纸 + 黑白方格壁纸，平移页面/弹层，比较玻璃中心（不折射）与边缘（最大约 2.4dp 位移），像素差有确定方向且不出现边界越界。
2. **前景清晰**：同一截图比较玻璃外/内文本、48dp 点击目标、滚动时字幕清晰度；不能使用整个 UI RenderEffect。
3. **对比/降级**：亮壁纸、暗壁纸、高对比图案、纯色、无壁纸、哑光主题、减少透明度、Android API 32/33/35/36/37；截图证明旧设备没有黑块或崩溃。
4. **性能**：Android 中端机连续滚动/弹层开合，记录 GPU 帧耗时、分配及耗电，光学通道相对 FROSTED 基准不得产生明显卡顿；必要时降低面积阈值、折射强度，优先关高阶效果。
5. **动效**：减少动画/用户节奏开关、横竖屏、IME、手势返回、弹层叠加；点击与状态不得因折射丢失。
6. **无白块回退**：七路由和现有设置二级页复查，明确记录普通列表没有恢复深层材质容器。
7. **交付**：`app` 编译、单测、Android 16/17 仪器测试、运行时光学像素对比、Figma 原生节点/变量检查及真机截屏。**光学像素测试与 Figma 仍待完成时，不得宣称“全面液态玻璃验收通过”**。

## 6. 下一阶段（未实现部分）

- **B / 捕获层**：经过遮罩与隐私评审的真实背景纹理宿主；异步缓存、裁切和像素时序同步；不能透出本不应显示的聊天文字。
- **C / 动态光场**：根据位置和触摸改变局部光源/高光，内建节奏和低功耗策略，不添加伪互动动画。
- **D / Figma/资产同源**：在线建立材质变量集、状态变体及 Code Connect；浏览器原型也要提供“毛玻璃 / 光学玻璃 / 不透明兜底”可交互切换。
- **E / 自动验收**：Android 光学截屏金样、图形探针、API 32/33 的差异测试、特效成本预算门禁。

本轮先完成可复用的 **A / 场景级光学折射基础**，不把 B–E 的目标包装成已实现。
