## 已提交的产品/实现改造

1. 统一聊天顶部/底部/侧栏、按钮及设置入口图标的 V6 三主题语义配色，用户指定强调色继续生效。
2. 通过全局背景坐标提供壁纸和三处柔光采样。玻璃层只模糊背景采样，不模糊文字；哑光、降低透明度及嵌套深度保留实色退化。
3. 侧栏检索扩展至真实聊天、任务和工作区文件，点击进入对应真实页面，不虚构索引结果。
4. 对聊天产物卡→工作区预览接入 `SharedTransitionLayout/sharedBounds`；本 PR 进一步加入相同 Work 会话下完成的目标卡→结果卡 Morph；它不能替代定时任务列表的独立身份，真实动效仍须验收。
5. 通知发送按完成、失败、需要处理、人物主动消息分组控制；免打扰覆盖跨午夜，失败/待处理继续送达。
6. 高使用频率的设置分组、外观预览、账户卡和模型资料卡改用 V6 L3 采样材质；模型/账户输入行与小型选择器改用 V6 L1 语义层，选中强调色仍独立保留。

以上是**代码实现口径**，不代表设备截图已逐状态与设计对齐。

### 已确认的根因与本轮修改

- **材质分叉**：设置分组和工具能力行仍直接使用旧表面或壁纸透明度策略，模型/账户卡则使用 V6 采样材质。设置首页及各设置子页的分组、工具能力行改为唯一 `SyMaterialFrame` 的 L3；保留专用内容结构与真实动作，移除工具图标的额外底色盒。
- **背景采样不连续**：原算法将源图裁剪范围夹到图片边缘后，仍拉伸至完整卡片尺寸，滚动/转场中部分越界时出现比例变化。改为以根画布同一缩放绘制完整图片，由当前表面裁切；嵌套卡片继承父层背底，避免重铺原始场景把父层材质清掉。无背景采样时按同一语义色板与画布合成退化；Matte/全实色层不绘制玻璃高光。`ShenyanSceneBackdropTest` 覆盖对应坐标、中心裁切、上下左右越界与缺失视口。
- **顶栏布局分叉**：运行中心、工作区、人物图集/详情、定时互动、工作任务、插件目录和工具管理恢复全宽顶栏。工作任务的正文边距留在顶栏下；项目管理的返回入口移出滚动正文，内容滚动时仍可返回。其他业务回调及导航归属保持。
- **强调色双投影遗漏**：已有 `harmonizeV6(... preserveAccent=true)` 只更新旧页面消费者，新库按钮/开关仍读默认色。现将同一已保存强调色投影到 canonical `LocalSyColors`，再装配兼容桥；三主题材质及成功/危险等状态色保持原语义，默认杏色保持。`ShenyanColorHarmonyTest` 遍历已有七种非默认色与三主题回归。
- **选择控件与大字**：空间导航的 modifier 归外层材质所有，选项居中、选中态及 48dp 触控保留；统一选择动效并遵守减少动态效果。通用分段使用语义选中底色；等宽选项可换行，非等宽选项可横向滚动，避免把任务数量/筛选标签裁掉。设置行在 1.2x 及以上字号将值移至说明下方，标题与说明允许展开。

本轮未新增、删除、迁移业务功能或改变入口归属，无需更新功能树；布局继续消费现有 presentation/Feature API，不读取领域 Store，不新增持久事实源。
