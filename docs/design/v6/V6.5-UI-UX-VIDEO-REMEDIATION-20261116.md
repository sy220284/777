## Android 36 原始界面证据与导航检查

首轮 `MainPagesAuditTourTest` 失败时，从 GitHub Actions 失败截图及 `main-tour-last-semantics.txt` 核实，前台确实停留在「定时任务」根页（顶部标题「定时任务」，有「新建自动化」图标）。此前测试在任务编辑器输入后依次按返回，但软键盘会先消耗一次返回；当任务编辑器仍在前台时，随后只退出编辑器，根页未完成关闭。

原生导航巡检已增加明确验收：按系统返回处理输入法后，若编辑器仍在前台则调用可见返回按钮；必须看到任务根页「新建自动化」入口，随后由外层 `page()` 的系统返回验证已回到对话输入区。任一阶段失败仍直接报错。
