# PR #654 新版替换进度

## 已完成的旧组件退出

统计口径：生产 UI 调用，包含 Kotlin 的 `Function(...)` 和 `Function { ... }` 两种写法；排除注释、字符串、测试和字体/设置语义映射。

本轮开始时：36 个业务文件、26 种旧 `Ds*` 绘制接口、201 处调用。本轮已全部替换到当前 `Sy*`；旧组件定义与生产调用均为 0。删除 30 份旧组件源码，触觉工具文件保留能力并改名为 `HapticFeedback.kt`。

- 按钮、卡片、页签、搜索、输入框、开关、勾选、进度、图标和底部浮层直接使用新版。
- 弹窗、菜单、Toast、时间线、值编辑行与输入区的旧绘制退出，不保留旧 UI 转接壳。
- 消息气泡、状态点、可展开工具详情、空态与设置开关行由原生新库绘制；壁纸亮度分析、字体偏好、业务状态与真实回调保留。
- 输入区原有测试标签值保留，测试入口改为新版；触控、菜单关闭、输入焦点、任务状态等原契约继续回归。

新版弹窗补齐长内容滚动、点击外部关闭、受保护弹窗、键盘与安全区域避让。上一 head 的 Android 16/17 各 4 项失败已按日志定位：大字顶栏副标题必须落在按钮行下方，可点击短标签必须同时满足 48dp 宽高，工具详情测试需要定位前景操作而非重名的后台按钮。修复源头并保留原测试断言；新的设备通过结果仍须看最新 CI。

当前验证状态以同目录 `verification.json` 为准。大规模删除后本地编译遇到 Kotlin/KSP 增量快照不一致，验证使用完整非增量重编译；没有关闭编译、lint、测试或门禁，也没有修改生产构建配置。
