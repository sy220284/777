# V6 页面动效与响应速度规范 · 2026-10-15

状态：PR #724 Android 代码候选实现；仍需 CI 与 Android 16/17 设备视觉验收。Figma Starter 调用上限已达，未修改 Figma 在线画布。

## 体验目标

操作瞬时响应，动画仅负责说明空间和状态变化：按压 70ms、选中 150ms、同级切换 140ms、进入 260ms、返回 220ms、弹窗 220ms、面板 280ms。使用同一条柔和缓动曲线，禁止过冲、大幅缩放、重复扫光或装饰性持续运动。真实运行状态例外，但完成、失败后不应保持脉冲。

统一通过 `SyMotion.duration(token, reducedMotion, tempo)` 计算时长；优先系统关闭动画，其次是应用的 0.7～1.3 倍节奏。对于无法由应用控制的 Android Material3 原生底部弹层，不宣称已覆盖其内部所有动画。

## 七个主页面的轻量差异化

| 页面 | 方向与质感 | 目的 |
| --- | --- | --- |
| 聊天/工作主页 | 导航短横移，输入栏短展开、淡入 | 确保阅读位置和输入响应稳定 |
| 人物图集 | 轻微从下上浮 + 淡入；前十项有限级联 | 轻柔呈现人物，不滥用重复动效 |
| 人物日记 | 极短向下进入 + 淡入 | 像展开读物一样自然 |
| 工作区 | 0.985 聚焦缩放 + 淡入 | 引导视线至真实文件 |
| 自动化任务 | 少量自下往上 + 淡入 | 把注意力导向当前状态 |
| 工具/插件/技能 | 0.975 聚焦缩放 + 淡入 | 轻快进入工具场景 |
| 设置 | 水平方向层级；外观/记忆轻纵移，模型/用量轻聚焦 | 体现层级与功能差异 |

共享页面切换主机实现这些差异：不是在每页叠加独立重型动画。设置子页面保持每次正确返回栈，滚动及业务状态不得因动画重建丢失。

## 组件行为

- 输入区展开、消息列表排布、人物选择、工具详情与任务状态使用统一时长；交互反馈优先于动画。
- 连续点击和中途返回必须正确呈现最新状态，不应等候入场动画结束才能操作。
- 高对比/壁纸/三主题均不依赖阴影和底板营造层次；不额外改变原视觉布局。
- 加号多模态图片/视频/配音/转写保留真实任务状态与可操作性，内容切换以响应为主，不叠加全页过渡。
- 侧栏会话左滑删除由 PR #720 独立移除，本次不恢复已取消的手势功能。

## 完成标准

1. GitHub PR 检查完成：编译、单测、设计系统门禁及 Android 16/17 仪表测试。
2. 核实每种页面入场、退出、快速往返、关闭系统动画、三档节奏、键盘和中断操作。
3. 测试 320/360/393/412dp 布局、文字放大、深色/浅色及壁纸，确保不过度重绘或阻塞内容。
4. Android 真机或模拟器交互录屏检查流畅度与卡顿。Figma 编辑同步单独核验，不得以本地代码或原型代替。
