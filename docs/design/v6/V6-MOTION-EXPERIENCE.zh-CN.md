## 1. 已实现的基础时序

| 类别 | 基准值 | 类别 | 基准值 |
|---|---:|---|---:|
| 按压 | 70ms | 选择 | 150ms |
| Dialog | 220ms | Sheet | 280ms |
| 层级前进 | 260ms | 返回 | 220ms |
| 同级切换 | 140ms | 侧栏 | 180ms |
| 工具展开 | 170ms | 工具详情延迟 | 55ms |
| 输入区展开 / 淡入 | 155/95ms | 普通淡入 | 130ms |

统一使用 `SyMotion.duration(token, reducedMotion, tempo)`，缓动 `cubic-bezier(.22,1,.36,1)`，节奏倍率 `0.7–1.3`；减少动画时非必要时长归零。Android Material3 内部不受本设计系统控制的过渡需单独核对。

## 2. V6.4 体验设计目标：更丰富的微动效

微动效用于显示操作结果和状态流动。保留短促响应，不靠放慢页面换取质感；持续运动只服务于真实运行态。

| 场景 | 新增/完善的微动效 | 结束与边界 |
|---|---|---|
| 输入区 | 聚焦时边缘光柔和变化、附件出现/收起带尺寸连续性、发送按钮与停止态正确互换 | IME 打开与折叠不挤掉操作，避免不必要跳动 |
| 发送消息 | 从输入态自然进入时间线，必要时轻淡入 | 以实际发送确认触发，不在失败时伪造已送达 |
| 工作步骤 | 当前执行项轻微呼吸、工具调用展开、完成项有短促收束 | 完成/失败/停止立即静止；未知进度不展示百分比 |
| 任务 | 开始、暂停、恢复、完成/失败就地状态变化 | 以真实任务回执为准，可查看失败原因 |
| 人物/技能 | 选择态轻聚焦、卡片展开/收拢、安装连接状态过渡 | 使用复用的组件和时序；连续快速操作无滞后 |
| 文件与成果 | 列表到预览位置与层级连续，完成后突出成果入口 | 返回恢复原列表位置，不强行整页缩放 |
| 审批/权限 | 弹窗与内层状态切换简洁清晰 | 授权仅以实际系统检测结果更新，而非打开设置后自动算成功 |

### 已经实现的动效：直接继承

- `LocalFeatureAnimatedHost` 统一维护页面栈、Predictive Back 手势进度及工作区文件的共享元素转场，后者由工作区路径和文件路径共同定位；系统减少动效时跳过非必要转场。
- `LocalTranscriptPagingUi` 已实现流式阅读的尾部跟随和历史阅读位置保护；新增页面入场或输入区形变不能把读者从历史位置拉回底部。
- Work 步骤已有六种工具状态。完成、失败、取消和结果未知必须静止并保留原始回执，新微动效仅在真实等待/运行或状态切换时触发。

实现条件、可复用组件和证据参见 [V6.3 已实现交互与组件契约](V6-IMPLEMENTED-INTERACTION-CONTRACT.zh-CN.md)。

## 3. 七条主路由动效语言

聊天/Work 以阅读流与输入区形变为主；人物图集以选中聚焦为主；日记以安静入场为主；工作区突出文件前后层级；任务突出状态；工具突出发现与安装；设置强调层级返回和就地改变。共享导航主机承载基础动效，页面不得各自复制页面级动画。

## 4. 性能和可访问性

- 页面跳转、组件展开不得阻塞真实点击或输入；中途返回和频繁切换按最后一次真实状态完成。
- 自定义壁纸/局部玻璃与动画同时发生时，优先保持高对比正文和稳定帧率；不要让一串列表行同时发光。
- 减少动画时，运动归零但状态图标、文字、任务可操作性保留。背景减少透明度独立于减少动画。
- 关键复查：320/360/393/412dp、字体放大、Android 16/17、软键盘、返回手势、TalkBack、低性能设备及 3 种主题。

## 5. 验收

原生 Compose 单元与仪表测试 + Android 实际录屏核验入场、返回、按压、连续点击、真实工作流及动画关闭后的状态。设计文档变动不等于业务代码实现；本轮不将任何微动效新增项记为已上线。
