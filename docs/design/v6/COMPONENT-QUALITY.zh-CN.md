本次依据仓库 UI/UX、V6 设计规范和用户授权的自主设计，检查 canonical 组件及其业务消费者。收尾时远端更新至 `6d471d39`，已纳入唯一手机原稿 `mobile/app.html`，遵守旧自主草稿删除，不重新发布重复版本。没有新增业务事实源、改动 Feature 归属或以截图示例替换真实数据。

## 唯一材质与自适应

`SyMaterialSurface` 是唯一绘制入口，`SyMaterialFrame` 只组织带内边距的 Column。迁移了 46 处旧中性 Surface：世界书、记忆、团队、人物图集、会话卡、生成媒体/附件、用量、定时互动、插件、群公告、成员选择和计划评审等。仍保留头像、真实媒体、语义状态和透明点击区的专用绘制。

L1 注释/指标/控件、L2 栏与输入、L3 内容卡、L4 浮层、L5 实色退化使用同一套填充策略。材质加入对齐的壁纸/根光场采样、独立底层模糊、渐变边缘高光与层级阴影；文字和图标不被模糊。这里的液体玻璃效果以这些原生层构成，**不具备任意同级内容折射或实时光学变形**，不能把背景模糊宣传成完整光学模拟。

背景图片在后台采样 24×36 个点，缓存上中下区域的平均 RGB 和最亮/最暗代表色；组件绘制不解码或扫描像素。填充最多带入 30% 区域色，相对六类文字墨色控制染色和透明度。开启自适应对比时按样本求解最低底层不透明度，代表性测试目标为 4.5:1；高反差图片可能需要更实的卡面。该采样策略不能替代对任意壁纸每个像素的设备检查。

跨 Dialog/Popup 使用屏幕坐标匹配根背景；嵌套表面继承父层，不重复铺原始壁纸。深层嵌套、减少透明度采用 L5；Matte 使用精确实色，关闭模糊及玻璃高光。用户关闭自适应对比时尊重透明度偏好。没有通过全局漂白壁纸来遮盖局部组件问题。

## 组件审计结果

| 家族 | 本轮处理 | 原生证据边界 |
|---|---|---|
| 页面栏、导航、分段、标签 | 同材质；明确文字/图标颜色；选择色过渡；大字换行与 48dp 触控 | 编译、行为回归；仍需真实页面截图 |
| 按钮、图标按钮、快捷入口 | 禁用/次要/选择态墨色；壁纸上次要按钮局部 L1 底层；按压反馈 | 组件设备回归新增，等待当前 CI |
| 输入、搜索、日期/时间 | 中性默认填充同策略，聚焦不再变大白块；保留原编辑节点、IME 和 testTag | 不用外层 Surface 改写文本编辑语义 |
| 复选、单选、开关、滑块 | 沿用受控状态及真实回调；选择态与禁用态颜色统一 | 不新增本地业务状态 |
| 内容卡、列表、消息、附件 | 46 处业务中性表面归一；选择与状态只作轻量染色；深嵌套实色退化 | 保留真实媒体/头像原图 |
| 标题、状态、提示、空/错/加载 | 状态标签用可读墨色；壁纸裸标题局部底层保护；既有语义/播报保留 | 不把运行、失败与等待状态混用 |
| 抽屉、Sheet、Dialog、菜单 | 同 L4 底层；平台外壳透明；弹窗对齐全局背景；深度统一 | 系统模态遮罩仍由平台承担 |
| 图集、工作进度、展开内容 | 入场、选择、展开/收起补齐减少动态分支 | 静态截图不验收动效时序 |

## 图标与动效

保留并继续使用 PR 的 26 枚重新绘制的功能图标；修复工具、能力目录、设置用量/存储/诊断、会话、群聊、人物和建议动作中漏接的功能入口。其余通用返回/关闭/编辑等控件线宽改为同一 1.75f 语法，未把照片或文件预览替换成图标。未使用的通用 TabBar 占位符不属于已上线入口。

补充抽屉前十项首入场级联、标签选择色过渡、展开/收起和材质点击按压；保留已有页面推入/返回、文件共享元素与工作完成转场。图集级联与工作阶段切换也遵循减少动态。减少动态不延迟可交互内容；Matte 的材质退化与减少动态是不同偏好。真实动效连贯性及帧预算仍需设备录像与性能证据，不能仅由静态截图判断。
