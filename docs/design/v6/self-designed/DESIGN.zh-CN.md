## 视觉基准

- **暖纸 Light**：暖米白画布、深棕正文、杏色主操作；留白组织信息，避免大块杏色背景。
- **烟熏 Dark**：暖黑画布和浅色墨线，卡面透出柔和暖光；细字使用可读的次级文字色。
- **哑光 Matte**：所有表面实色，保留层级与边界；不模糊、不绘制玻璃高光。
- **材质**：L1 为注释、指标和内嵌控件；L2 为导航和输入；L3 为主要内容；L4 为浮层；L5 为实色退化。同层材质使用唯一 `SyMaterialFrame`，状态边框通过其参数表达。
- **语义色**：杏色表达主操作与选择；薄荷表达真实运行/完成；警告表达待处理/阻塞；危险色表达失败或破坏性操作。失败、暂停、等待不冒充运行或成功。
- **圆角**：9 / 13 / 18 / 24dp 对应小元素、控件、卡片、浮层；触控至少 48dp。视觉和命中尺寸分开。
- **排版**：顶栏标题 17–20sp；分组标题 14sp 半粗；常规正文 14–16sp；聊天与日记正文 15sp / 26sp 行距，沉浸阅读 17sp / 28sp。字体、字重和 1.5 倍有效字号上限继续来自应用偏好。
- **密度**：页面边距约 18–22dp，组内间隔 6–10dp、组间 14–22dp。高频信息在首屏，低频管理进入菜单或下一层。
- **动效**：沿用当前单一动画事实源，解释选择、页面层级、工作状态；减少动态效果时停止位移或缩短切换。正常、完成、失败不因装饰需要持续运动。

## 场景构图

1. **聊天 / 阅读 / 日记**：正文占据视觉中心，操作靠边；不把每段内容塞进同类参数卡。普通聊天提高正文行距；沉浸阅读使用文章宽度与段落留白；日记保留日期、事件、来源及纠正动作。
2. **工作 / 运行中心 / 代理团队**：目标、当前进展、阻塞分别呈现；大字下目标不与证据动作争宽。任务和代理成员保留专用状态、操作与展开内容。
3. **任务计划 / 编辑 / 定时互动**：列表先显示状态，再显示任务与时间；一条任务只有一处真实时间投影。状态、周期和免打扰标签允许换行，长标题保留可读空间。编辑仍按目标、计划、通知分区。
4. **人物 / 图集 / 群聊**：照片承载身份，故事承载关系；列表浏览与管理分开。群聊隐私说明使用安静 L1，选择结果与提交保持显式。
5. **文件 / 工具 / 媒体**：保留文件类型、路径、工具可用性和模型来源。媒体按照类型、模型、输入、参数、历史分区；没有可用模型时显示语义空态；次要操作允许换行。
6. **设置 / 账户 / 用量**：设置分组标题在卡外，账户状态在身份下方；账户管理使用两列操作，避免四项挤在一行。用量总量、模式指标、趋势与请求分源；趋势筛选不挤压标题，指标使用 L1 小面。
7. **空 / 错误 / 加载 / 首次引导**：一个明确视觉锚点、原因说明、最多一个主恢复动作；加载可播报，禁用态可辨。引导适配安全区和滚动，不在大字时裁掉底部开始按钮。
