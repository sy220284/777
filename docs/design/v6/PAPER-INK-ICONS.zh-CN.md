# 777 · 暖纸墨线图标素材与替换

按照用户确认的参考图片：暖纸底、低饱和浅色块、墨色细线、圆角细节。**参考图的山景与装饰纹理不裁入图标**，以便应用原有深浅色主题继续工作。

正式现行入口 24 枚，另补充能力中心关联语义图标（技能、插件、连接）3 枚。完整设计源为 `paper-ink-icon-catalog.json`，对应可编辑 SVG 分别在 `assets/icons/`（现行）及 `assets/icons-supplemental/`（补充）；`sy-entry-icons.svg` 为整体总览。Android 实际使用的矢量路径在 `SyEntryIcons.kt`，不依赖截图裁剪或网络素材。

标准：24×24 viewBox，1.75 描边，round cap/join。墨色参考 `#302B27`；六种低饱和承托色属于 UI 容器，不写死在图标矢量文件里。白天采用柔和配色，夜间/哑光主题采用原有暗色容器与浅色描边，保证对比度。触控区域遵循原控件尺寸。

替换范围：全部现行入口矢量、侧边栏入口、设置导航、能力中心语义入口。连接入口弃用旧 Projects 图标，HTTP 连接按钮使用链条图标。普通操作（复制、分享、下载等）保留已经完成 1.75 描边统一的现有 61 枚通用操作矢量，避免再次出现第二套资源。没有改路由、功能逻辑或系统品牌图标。

校验：`python3 docs/design/v6/audit-all-icons.py` 逐路径比对目录、Kotlin 与 SVG；GitHub CI 构建与界面测试检查运行接入。
