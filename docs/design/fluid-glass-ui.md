# 流体玻璃 v1.4 · Android 落位

设计依据：用户上传的 `777-design-v1-1.zip` 与 `777-design-v1-preview-1.zip`，其中 README 自称 v1.4。包内实际为 HTML、说明和 7 张桌面截图，不含其 README 所述 Kotlin 文件。Android 继续使用现有 Compose Feature UI，业务与运行时所有权不变。

## 视觉与手机适配

暖米白 `#EDE6DA` 画布，静态橙 / 薄荷 / 淡紫径向光场；卡片白色 62%、输入 82%、手机抽屉与浮层 96%。手机浮层覆盖真实文字，不直接照搬桌面侧栏的 46% 透明度。最多使用局部表面，不增加实时背景模糊或永久装饰动画。自定义壁纸仍由原分析策略控制；磨砂黑保持独立外观。

主操作杏色底配深棕字，人物紫色，运行 / 正常额度薄荷色。细字使用可读的深一档墨色；设计稿淡灰只用于禁用和装饰。显式蓝、青瓷等用户色卡继续可选，旧默认 `celadon` 跟随流体杏。现有中文字体、代码字体与用户字重 / 大小偏好继续生效，不从网络临时补字体。

圆角统一为 8 / 13 / 20 / 24dp；用户气泡右下 7dp，人物气泡左下 7dp。触控至少 48dp。页面 push 480ms / 20dp，peer swap 380ms，Dialog 280ms / .92→1，按压 80ms，颜色 140ms；系统 Sheet 保留平台拖拽与返回实现。预测返回继续直接跟手。状态动画只由真实运行驱动。

## 页面映射

| 设计稿视图 | Android 功能入口 / 表面 | 处理原则 |
| --- | --- | --- |
| 01 聊天、10 群聊 | 聊天主界面、人物 / 群聊头部、共用 Composer | 人物玻璃气泡、用户杏色气泡；附件、发送、停止、分支保留 |
| 02 工作、03 运行中心、13 任务编辑、17 团队、37 完成 | Work 主界面、运行中心、团队 Sheet、任务列表 | 真实目标 / 计划 / 问答 / 审批 / 工具状态；过程默认展开，完成不自动折叠 |
| 04 用量 | 设置用量页；MiniMax 官方额度从侧栏直达 | 本地 Token 和官方套餐继续分源；数字、进度与重置时间并列 |
| 05 阅读、11 消息 | 原生消息操作、文本阅读 / 编辑 Sheet | 复制、重发、重新生成、分支、媒体保留；不造假媒体 |
| 06 图库、07 档案、08 世界书、09 日记、12 定时互动 | 人物图集 → 详情 / 故事 / 档案；角色日记；聊天任务 | 复用现有关系、记忆、世界书和故事状态；不恢复已退役军师 |
| 14 能力、15 工作历史 | 工具发现面板、运行中心工具执行历史 | 沿用 ToolRouter 投影与 EventLog；原文恢复从详情主动查看 |
| 16 工作区 | 项目、文件、会话产出 | 项目单列选中行 + 分组编辑，创建 / 改名 / 规则 / 删除与恢复不变 |
| 18 插件、19 计划 | 工具中心 → Skills / GitHub / MCP / Webhook；任务页 | 保留已有连接 / 启停 / 轮换 / 触发入口，不把截图中连接当成已配置 |
| 20–30 设置 | 现有设置首页与子页 | 共用棕色文字层级、玻璃组面与透明顶栏，移除设置专用纯黑覆盖 |
| 31 引导、32 权限、34 空态、35 错误、36 通知 | 现有启动、权限、状态反馈与 Android 通知 | 根据真实状态出现；不额外加一次性引导阻塞现有用户 |
| 33 搜索 | 侧栏会话搜索、已有各页搜索 | 不将桌面 ⌘K 当成手机一级入口或伪造跨域搜索 |
| 38 媒体 | 当前模型支持的原生媒体入口 | 仅展示现有主线能力；设计稿未合并的 provider 扩展不靠 UI 宣称可用 |

这张表是功能落位和共享设计覆盖范围，不是“38 个页面像素验收通过”的记录。现有业务页已接入共享 Design System；桌面四栏人物 Tab、多 provider 媒体等扩展布局不视为已交付的新业务能力。

## 验证

CI 在 Android 16 / 17 运行现有完整设备回归后，从 debug 截图宿主渲染真实生产组件，输出导航、聊天、工作、用量与额度的浅 / 深两组 PNG。截图使用标明的固定样例，不连接真实账户，不能当成真实任务执行证据。截图存入 `fluid-ui-android-16` / `fluid-ui-android-17` Artifact。完整 CI 通过和人工查看截图后才能视为验收完成。
