# 神言神语 V5 → 777 原生 UI · PR #654 唯一迁移契约

> 设计来源：用户批准的 `shenyan-ui-v5-full-scene-design-20261012.zip`。
> 页面权威稿：`app.html`、`assets/shenyan-v5-app.css`、`assets/shenyan-v5-app.js`；
> 组件：`components-v4.html`、`compose-v5/`；文字规范：`V5-SCENE-DESIGN-SYSTEM.zh-CN.md`。
> 这些源文件来自用户提供的离线设计包；**不要在生产 App 中运行 HTML，绝不复制其假数据**。

## 禁止偷换验收范围

- 旧 `Ds*` 视觉组件全部视为 **deprecated**：仅允许过渡期间保留原调用签名，真正绘制必须进入 `ui/shenyan/Sy*`；逐屏改完后删除兼容层及其测试/引用。
- 本次提交的 `SyThemeProvider` 接入所有屏，`SyMaterialFrame` / `SyButton` / `SyResponsiveSheet` 和旧入口委托 **仅为第一批底座接入**；绝不把新目录存在或编译通过等同于 38 屏完成。
- 业务导航、会话/人物记忆、工作任务、模型切换、工具授权、通知、诊断、壁纸亮度分析、IME、预测返回、输入历史必须保留实际回调和持久化。
- 新组件单一设计源：颜色/材质/间距/尺寸/动效来自 `ui/shenyan`，不允许在屏幕里复制渐变、硬编码颜色、手写新卡片。
- 主题三态：Light 暖纸＋暖杏，Dark 烟熏玻璃，Matte 全实色零模糊。L1/L2/L3 透明、L4 可读浮层、L5 实色；最多三层玻璃祖先。全局顶部栏必须为实色。
- 最小触控区域 48dp；减少动态效果与减少透明度分别处理，文本/图标不模糊；退出和危险操作不得虚假执行。

## 当前已经提交的原生基础迁移

1. `SyThemeProvider` 自 `DshTheme` 根部提供 V5 的语义色、五层材质和全局触控/动画尺寸。
2. 新 `SyMaterialFrame` 只模糊显式传入、空间对齐的 backdrop；无背景样本不伪装“真正原生玻璃”。被动卡不提供虚假的禁用按钮 TalkBack 语义。
3. 新 `SyButton` / `SyTabs` / `SyStatusLine` 与适配 `DsButton`、`DsCard`、`DsSegmented`、`DsProgressBar`、`DsSearchField`。兼容外壳必须在逐屏迁完后删除。
4. 新 `SyResponsiveSheet`：手机底部 Sheet、>=600dp 右侧浮层，使用真业务内容、受控关闭回调；保留旧 `DsBottomSheet` 名称仅过渡。
5. `LocalHarnessScreen` 在 >=1024dp 用常驻 258dp 抽屉，支持 64dp 收起；>=1440dp 的 HOME 添加真实数据 318dp 信息栏；手机保留原会话抽屉与生命周期。
6. `DsTopBar` 改用 V5 实色顶部栏、页签使用 V5 玻璃选中层。
