> V7 / V8 两轮视觉方向已按用户要求整体清理，目录不再保留；回溯可在 GitHub 已关闭的 PR #939（V7）、#941（V8）查看当时的完整 diff。

| 目录 | 性质 | 说明 |
|---|---|---|
| `v6/` | **现行生产设计** | V6「暖墨 · 精密玻璃」是当前 App 的真实设计来源，在 V9 落地前继续有效；其中的 `current-ui.json`、纸墨图标与规范仍被 V9 引用 |
| `v9/` | **新方向（待实施）** | 视觉说明、三层令牌与校验脚本、离线交互稿与渲染截图 |
| `baseline/` | **事实底账** | 现有视觉系统真实值（逐条标 `文件:行号`）、落地前必须解决的工程根因、功能地图与体验审计 |
| `mobile-ui.md` | 现行规范 | 人物图集、媒体创作等专用规范 |
| `context-cost-and-route-health.md` | 专项分析 | 上下文成本与路由健康度分析 |

## 规则

- 设计只有**一个**有效版本；新方向落地前，旧方向降级为历史留存，不并行维护。
- 令牌唯一事实源在 `v9/tokens.json`，派生值由脚本计算，不手写第二份。
- 视觉改动与功能改动不混在同一个 PR。
- 任何 PR 需先经用户确认再创建；平时只推分支供评审。
