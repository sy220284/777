# 朝夕 E8.17｜三个 PR 的设计审计与合并说明

审计日期：2026-10-18。基准：UI 3.0 权威规范、朝夕 E8.17 原设计包及《朝夕E8.17-全页面布局一致性审计-20261018.md》、`docs/design/zhaoxi/PROGRESSIVE-REPLY-ACCEPTANCE.zh-CN.md`。来源：#742、#743、#744。

## 整合决策
- 以 #743 为底座：保留侧栏、主页布局、导航、设置背景材质控制、程序化背景、原生图标、自适应启动图标和主页返回测试。
- 纳入 #742 的 48dp 发送/停止、禁用态、普通 Chip 与 Tab 的语义区分、通用空态。其旧导航/空会话方案由 #744 覆盖，避免双标题栏和双空态。
- 纳入 #744 的新顶部导航、Chat/Work 空态、回复边距、轻量历史入口、减弱动效停用循环动画、场景 Compose 子树截图和 3 组浅/深/130% 富文本夹具。
- #743 的主页测试已经改为抽屉导航及 Android 系统返回，#744 同一文件的旧式返回控件测试补丁不再适用，以 #743 为准。
- 只提取 #744 的补丁，避免将其旧功能分支（与 main 的提交历史分叉）整体混进来。
- 保持 #740 已合并的唯一渐进式回复通道；Host/Owner/Feature Ports 与既有安全/持久化契约不变。

## 设计差距及验收边界
- 此次三个 PR 的改动范围有限；既有 25 页全页面审计仍为 7 项部分符合、15 项结构偏差、3 项待验。人物编辑器、工作区、工具与 MCP、用量日志、任务、权限通知等独立布局尚未因本次整合被补齐。
- 原 E8.17 背景素材 10 张 PNG 仍未证明导入运行包；本 PR 保留 #743 程序化环境光背景，不能宣称与原 PNG 完全一致。
- Figma 文件 `oHivuQziUC5AbWET9tJXX9` 既有审计记录为限额无法逐层取稿；本审计依据本地设计包和已记录的设备截图，未完成 Figma 逐像素认证。
- #742 旧 Head 的静态门禁因缺失启动图标失败，#743 已补齐且独立静态检查通过；#744 既有成功 CI 不能代替此整合 Head 验收。

1. 该 PR 最新 HEAD 通过所有静态、架构、JVM、Android16/17、ARM64/x86 检查。
2. 在实际生成数据中验收消息持续增长、工具等待/失败、审批、历史分页、长内容尾随和 TalkBack；静态富文本夹具仅证明排版渲染。
