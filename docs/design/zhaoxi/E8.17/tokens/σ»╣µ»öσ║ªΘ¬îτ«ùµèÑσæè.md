# 朝夕全色板对比度验算报告（E8.8 · WCAG 2.1 算法实测）

算法：相对亮度 L = 0.2126R+0.7152G+0.0722B（sRGB 线性化），对比度 = (L1+0.05)/(L2+0.05)。
判定：正文/次级/链接 ≥4.5:1；ink-3 按规范仅限非信息性装饰用途（时间戳、占位），不适用 4.5 门槛。

## 规则（E8.8 起生效）

1. 文字/链接一律 `--accent-ink`；`--accent` 仅填充、进度、描边。
2. 成功态文字用 `--ok-ink`；`--ok` 仅填充与描边。
3. `--ink-3` 不得承载唯一信息（必须可由 ink-2 元素或图标替代理解）。
4. 禁用态 = 40–50% 透明 + ink-3，属「刻意不可读」语义，不参与对比度判定。
