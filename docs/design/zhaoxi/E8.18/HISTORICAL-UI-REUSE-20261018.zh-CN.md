## 与 #758 需求规格的真实集成

本分支直接同步 #758 复核后的完整需求规格、251 个历史关键 PR 及主线 75 场景核对表；#755 集成分支新增 `settings.approval_mode`，因此**待审计集合为 75 Pack 场景 + 新审批场景 + 3 Host 场景**。不应将 75 改写成“已经验收的 75 张页面”。

本轮新增的用户路径：
- 侧栏顶部新建当前模式会话、全域搜索；Chat/Work 切换后保留侧栏，历史会话只显示相应模式；当前会话按 Owner 真实身份标示。
