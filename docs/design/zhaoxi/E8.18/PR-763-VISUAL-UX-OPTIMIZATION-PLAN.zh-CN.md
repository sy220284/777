# PR #763｜视觉与使用体验优化方案（2026-10-19）

> PR #763 已于 2026-10-19 合入 #760；本轮是 #763 视觉优化的**后续补丁**，提交至现存目标分支 `feat/zhaoxi-ui-visual-experience-20261019`（#760），**不推送 main**。参考 E8.18 Design Tokens、已登记的 `aesthetic-ui` / `ui设计` 相同视觉评估框架、PR #760 审计评论和 Android 16/17 截图证据。优先解决使用障碍，而不是机械增加卡片、说明和动效。

## 视觉系统与产品原则

1. **主次明确**：每屏一个最重要的任务；首屏优先呈现“当前状态→主要行动”，其他能力通过轻量折叠访问；不重复解释功能是什么。
2. **少层级、轻质感**：沿用 Zhaoxi Theme 的 `bg / bg2 / card / ink / ink2 / accent` 与 16dp 圆角、按压反馈，禁止另建色板；设置一级菜单只有图标、名称和必要动态状态。
3. **拇指可达且无障碍**：长表单的提交动作固定底部，与 IME 键盘避让联动；主要交互区域尽量符合至少 48dp 触控目标；验证 200% 字号、窄屏、多语言长字符串。
4. **状态真实**：授权开始、等待浏览器、取消、验证、错误分别来自现有 Owner 状态；按钮按可用性展示，不把“已请求”写成“已完成”。
5. **失败可恢复**：取消模型编辑前保护未保存草稿；API Key 不回显；错误不清掉表单；危险删除仍保持二次确认。
6. **动效保留而非滥删**：用已有 `ZhaoxiMotion` 动画入口和 reduced-motion 约束表现层级变化；不为微小数字变化引入无意义的动效。

## 必须复查的状态矩阵

- **布局**：窄屏、小屏 + 正常与 200% 字号；浅色／深色；键盘弹出、收起及长内容滚动；长模型名、长账户名、长错误文本。
- **账户**：未登录、首次登录、等待浏览器、点击取消、已登录未授权、套餐已授权、多账户切换、失败后重试；首次登录期间不依赖 `pendingAccountId != null` 才能取消。
- **模型**：无模型、有模型、目录空／报错、测试失败、编辑已保存模型、修改尚未保存、按系统返回和页面返回、保存后切换。
- **自动化**：无任务、已有任务、新建、修改、计划／自然语言两种模式、被删除任务、跨会话只读、大字号滚动与固定提交区。
- **其他**：工具/插件状态密集列表、工作区／文件产物、价格的峰谷/缓存金额、人物编辑、主首页／侧栏、删除风险对话框。
