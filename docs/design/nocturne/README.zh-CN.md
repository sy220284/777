## 新的视觉组织

- 聊天：人物图像在右侧融入场景，与渐隐遮罩一起退出正文阅读区；人物名字、故事状态、回复、输入操作形成单一阅读路径。
- 人物：正在继续的故事成为完整封面，其他人物是更紧凑的肖像收藏。资料、故事、关系继续从人物详情进入。
- 工作：紧凑的执行检查点、待确认事项、交付文件与输入分层；不把所有内容包进同一种大卡片。
- 文件：路径与文件行，保留搜索、目录与导入。
- 日记：大日期和独立阅读纸面，保留人物、来源与回溯入口。
- 自动化：时间、任务与状态直接可读；操作进任务详情。
- 能力中心：插件、技能、连接分开；授权与实际可用状态不混淆。
- 设置：账户与配置分组；降低装饰，让表单与搜索稳定。

页面使用实际模块标题和内容，移除上一版的大段导览口号。品牌识别来自人物图像、深浅层级、形体和色彩职责。

## 颜色、组件与运动

默认预览为深色：背景 `#0C0E14`，面板 `#171B25`，次级面 `#202635`，正文 `#EFF2FA`，辅助字 `#A0A9BE`，交互蓝 `#4969E8`，链接 `#B0C3FF`。浅色独立配置为冷银白与墨蓝。蓝色只承载动作与选中状态，待确认用暖金，错误用独立风险色。

原型按390px宽画面设计，触控目标48px，正文约16px。角色封面、执行面板、文件交付卡、列表、设置组和输入区使用不同构造，保持同一圆角与边界语言。图像复用仓库现有预设资源，不新增网络图片依赖。

页面进入240ms，底部弹层260ms，抽屉240ms，按压100ms；减少动画时取消位置和缩放。状态变化不等待动画结束。以上为设计预览的CSS时长，不能当成Android逐帧实测结果。
