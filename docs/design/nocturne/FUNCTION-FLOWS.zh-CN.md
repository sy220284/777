# 777 星幕 · 模块与界面运行图

基准：`main@5fbfb372`。本文件说明重新设计需要保留的产品行为；没有把设计示例当成运行事实。

## 入口与所有权

`LocalFeatureCatalog` 注册六个 Feature、七个稳定路由。`LocalFeaturePageContent` 按唯一 Owner 选择贡献；`LocalHarnessScreen` 承载栈、抽屉与会话，不接管 Feature 的写入。

| 一级路由 | 实际入口 | 状态来源 / 提交方式 |
| --- | --- | --- |
| HOME | `LocalConversationSurface` | 聊天/工作 presentation；发送、停止、排队、当前轮干预由既有动作执行 |
| PERSONA_GALLERY | `LocalChatUiContribution → PersonaGalleryScreen` | 图集、人物和故事的 Chat 动作；切回首页等待对应会话确实加载 |
| DIARY | `LocalChatUiContribution → CharacterDiaryScreen` | 日记读取、修正、停用和来源会话定位分别走原动作 |
| WORKSPACE | `LocalWorkUiContribution → LocalWorkspaceFilesDialog` | Work 文件动作；打开路径与入口请求参与导航和选择作用域 |
| TASKS | `TasksScreen` | Automation 任务状态、操作忙碌集合、编辑保存回执 |
| TOOLS | `ToolsScreen` | Tools 状态与实际目录；详情中的安装、连接和授权沿用原 ViewModel |
| SETTINGS | `SettingsScreen` | 设置页栈与搜索索引；配置提交仍归实际能力 Owner |

源码目录均位于 `app/src/main/java/com/labteto/dshmobile`。运行与数据边界详见 `docs/ARCHITECTURE.md`。

## 聊天与人物

入口：选择已有会话 / 新建 / 图集继续 / 群聊。

1. 恢复 Session 与其人物、故事和模式；输入框保留草稿和附件。
2. 选择模型、思考档位及当前可用能力；附件导入显示实际处理状态。
3. 发送后显示流式正文；运行中的主要按钮变为停止，停止交给真实运行 Owner。
4. 群聊显示成员与当前发言人；退出群聊、换人物、新会话、置顶、重命名、删除保留原入口和禁用条件。
5. 图集继续明确人物 ID 和故事 ID，不用人物名称或“当前故事”猜测归属。未保存修改仍提示保存，失败保留当前编辑。
6. 图集详情保留资料、肖像、故事、历史消息分页、检查与建议、导入导出、删除故事/人物、创建新故事等流程。
7. 图集管理使用原列表，保留多选、置顶、拖动排序和操作回执；浏览使用新的肖像封面。
8. 日记从原记录投影出日期与正文，仍能展开来源记录、纠正或停用并返回对应源消息。

星幕设计 优先展示人物名、关系上下文和正文，长操作进入详情与弹层。人物封面没有图片时用文字封面，不借用其他人物图片。

## 工作、工具与交付

入口：工作会话 / 文件触发 / 自动化运行 / 工作会话历史。

1. 用户描述目标，可带附件、计划模式或团队派发。
2. 原 Agent / Tool 运行持有 Run 与配置身份；界面消费公开步骤、工具状态和回执。
3. 等待审批、等待提问、工具运行、后台等待、失败和完成分别展示；关闭弹层不自动同意。
4. 运行中补充要求保留“干预当前轮”和“下一轮排队”的区别；关闭干预选项恢复下一轮默认。
5. 团队的成员、子任务、返回和汇总仍使用真实计数；成员已返回不等于成果已合并。没有任务总量时不生成假百分比。
6. 工具回执、调查线索、文件链接和成果版本继续可展开。顶栏摘要与会话菜单共用已有工作记录/交付动作。
7. 只有原写入回执确认的成果才显示正式保存；文件刷新失败与写入失败不混为一个成功/失败判断。

星幕方案围绕这条真实链路组织共用表面、字号、状态、页栏、抽屉和弹层；HTML 中的周报步骤和文件是构图样例。

## 文件与项目

入口保留任务、成果、其他文件和项目管理。浏览目录 → 路径导航 → 文件预览 → 编辑/打开/分享；更多操作保留项目、代码审查与下载。

- 搜索结果可以显示完整相对路径，不仅显示同名文件名。
- 选择状态由现有 `LocalFileSelectionUi` 管理；普通刷新保留选择，完整目录结果才核对已消失文件，分页缺席不是删除。
- 项目/目录/分类/入口请求变化依旧参与选择与预览作用域。
- 导入展示实际处理中和结果，不凭界面动画判定导入完成。
- 预览保留长文件分页、附件与文档入口，返回先退出预览/下级目录。

星幕设计 加强文件名和元信息的字号，选中态使用清晰的实体底色，浏览页保持稳定的文件行。

## 自动化

入口：手动新建、从对话创建、打开已有任务。

编辑内容与调度 → 提交保存 → 受理回执 → 真实任务状态 → 到时后台执行 → 结果会话 / 交付。操作可为暂停、恢复、取消、立即运行、再次编辑；`busyIds` 与保存状态继续约束重复操作，拒绝和异常保留反馈。一次性任务、循环任务、等待用户、执行中、已暂停和终态使用现有状态判定。

星幕设计 将状态、任务标题和下一次执行/上次执行时间排列为更明确的时间行。筛选数量来自真实任务，筛选为空不伪装为整体没有任务。

## 能力中心

- 插件：发现 / 已添加、搜索和用途筛选 → 完整详情 → 来源/权限 → 安装和启用 → 原始结果。
- 技能：发现 / 已添加 → 文件与说明 → 安装/编辑/删除 → 实际技能目录刷新。
- 连接：现有连接 / 添加连接 → 端点与凭据 / GitHub / OAuth → 授权回调 → 注册与工具发现 → 健康状态。
- 已安装、已授权、已注册、已发现工具、健康可用是不同事实；打开授权网页和安装按钮动画不算成功。
- 返回目录保留当前页签与查询，切换页签不额外重新拉取全部目录。

星幕设计 用清晰页签、来源和状态组织信息，短参数使用弹层，长详情继续用完整页面。

## 设置的全部二级入口

页面以 `SettingsDestination` 和 `SettingsSearchIndex` 为准，搜索仍执行原跳转、锚点定位与返回恢复。

| 分组 | 子页面与功能 |
| --- | --- |
| 体验 | SESSION 会话；APPEARANCE 明暗、配色、阅读、壁纸、透明度、环境光和动效；CHAT 聊天偏好 |
| 模型 | MODELS 提供商、API模型、图片输入；MODEL_PERFORMANCE 思考、温度、上下文与性能；ACCOUNT 账户与授权 |
| 用量 | MODEL_USAGE 模型用量；MINIMAX_QUOTA 配额；PRICING 定价；USAGE 消耗计算；USAGE_LOG 请求记录；USAGE_DETAIL 单项详情 |
| 记忆 | MEMORY 总入口；MEMORY_SETTINGS 规则；MEMORY_MANAGEMENT 内容搜索、类型与分页管理 |
| 设备 | PERMISSIONS 执行确认、无障碍、通知读取、虚拟显示等；NOTIFICATIONS 系统许可、任务通知与免打扰 |
| 维护 | ADVANCED 运行策略等；SESSION_STORAGE 存储/备份/导入导出；DIAGNOSTICS 运行诊断 |
| 导航 | ROOT 分组入口；SEARCH 别名检索、定位与返回恢复 |

配置输入 → 对应 Feature / Shared 配置 Owner → 成功/失败回执 → 页面投影。秘钥不进入可恢复 UI 状态；首次引导和系统授权继续保留最新主线的初始化与返回检查。星幕设计在预览中体现这些既有表单的分组与控件方向，原生实现尚未替换。

## 所有场景必须具备的状态

| 状态 | 用户看到什么 | 可执行动作 |
| --- | --- | --- |
| 初始为空 | 对应任务解释，不使用假数据填充 | 创建、导入或配置 |
| 加载/运行 | 当前真实步骤或不确定进度 | 等待、按原契约取消/停止 |
| 等待用户 | 具体问题、授权范围或待确认事项 | 明确确认、拒绝或稍后处理 |
| 成功 | 持久化/执行回执和可访问结果 | 查看、继续或分享 |
| 失败 | 可理解原因和现有内容 | 重试原操作、修正输入或检查配置 |
| 取消/中断 | 已停止或状态尚待核实 | 查看结果，不擅自重放副作用 |
| 重开/恢复 | 已恢复的真实 Session、任务或配置 | 沿原 Owner 继续，不重建一份任务 |

设计及源码变更不等于所有运行分支已经实测。原型检查、静态检查、JVM、Android 编译和设备回归分别记录。
