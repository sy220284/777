# 神言 V9 · 极简界面设计（Minimalism & Swiss）

> **性质：全新方向，取代 V8 与 V7。** 依据 ui-ux-pro-max 检索命中的 **Minimalism & Swiss Style** 与 **AI-Native UI** 两条风格线重做，目标是**高级感 + 清新简洁**：少结构、少容器、少装饰，靠排版与留白建立层级。
> **机读令牌：** [tokens.json](tokens.json)｜**校验：** [resolve-tokens.py](resolve-tokens.py)（64 项全过）｜**离线稿：** `mobile/app.html`

## 1. 技能检索依据

| 查询 | 采纳 |
|---|---|
| `--design-system "minimal premium ai chat app fresh airy light refined typography"` | **AI-Native UI**（minimal chrome、ambient 层级、流式文本、context cards）；反模式：heavy chrome、slow response feedback |
| `--domain style "minimalism swiss editorial clean premium light"` | **Minimalism & Swiss**：白空间、几何布局、无衬线、高对比、网格化；实现要点——`no shadows unless necessary`、单一强调色、无渐变 |
| `--domain typography "clean modern sans legible chinese premium quiet"` | 中文 **Noto Sans SC**（仓库已内置 `ui_noto_sc_*` 子集，不新增字体）；拉丁沿用 Outfit（与 DM Sans 同族的几何无衬线） |
| `--domain color "premium minimal neutral accent monochrome"` | 单色阶 + 单一强调色；弃用 AI 紫/青等通用 AI 配色 |

技能返回的落地页 Pattern、渐变、彩色图标容器、落地页 CTA 等与原生 App 无关，一律**不采纳**。

## 2. 结构上的根本改变（不只是换色）

V7/V8 的骨架是「卡片 + 分隔线 + 顶栏实底」；V9 把它拆掉：

| | V8 | **V9** |
|---|---|---|
| 顶栏 | 实底 + 底部分隔线 + 居中标题 | **无底色、无分隔线**，大标题左对齐 21px/600，字距 -0.02em |
| 列表 | 分隔线 + 行图标 | **无分隔线**，靠分组小标题 + 40px 分区间距分组；行高 60 |
| 卡片 | 抬升面 + 暖边 + 双层阴影 | **面板是唯一用阴影的容器**（1px 极轻阴影），其余靠留白与明度差 |
| 输入区 | 悬浮大圆角卡 + 阴影 | **无缝底栏**：canvas 底 + 一条 1px 细线，输入框无框，发送键 36dp 方圆 |
| 用户消息 | 淡染气泡 20dp 圆角 | sunken 底 12dp 圆角，更克制 |
| 工作步骤 | 状态轨 + 阴影卡片 | 细轨 + **左侧 2px 状态色条**，无卡片 |
| 画布 | 纸纹 + 暖光 | **纯冷调近白**，只留一道 6% 强调色的顶部微光 |
| 动效 | 80–300ms | **80–260ms**，无回弹，缓动 `cubic-bezier(.2,.8,.2,1)` |

## 3. 色板（冷调单色 + 单一强调）

| 角色 | 清露（浅） | 夜青（深） | 纯黑（哑光） |
|---|---|---|---|
| 画布 | `#F7F8FA` | `#0C0E10` | `#0A0A0B` |
| 表面 | `#FFFFFF` | `#14171A` | `#101112` |
| 下沉（选中 / 气泡 / 输入槽） | `#EDF0F3` | `#1B1F23` | `#17181A` |
| 正文 | `#14171A` | `#F3F5F6` | `#F4F5F6` |
| 次要 | `#565D64` | `#AAB2B8` | `#AEB4B9` |
| 三级 | `#616972` | `#848D94` | `#838A90` |
| 分隔线 | `#E7EAEE` | `#23282C` | `#1E2124` |
| 强调（深青） | `#0E6E78` | `#4FD1D8` | `#46C4CB` |
| 强调上的文字 | `#FFFFFF` | `#032629` | `#042629` |
| 成功 / 警告 / 危险 | `#16794F` / `#9A6B12` / `#B42318` | `#4FBF9A` / `#E0A458` / `#F0837B` | 同深色 |

- 单一强调色贯穿：主按钮、进行中状态、发送键、选中态、链接、开关开启。
- 八张强调色卡保留 App 现有持久化 key（`zhusha` / `xianghuang` / `celadon_explicit` / `dailan` / `zitang` / `yanzhi` / `yushi` / `songshi`），只换显示名与色值；前景由求解器按最终填充色计算。
- 对比度：正文类全部 ≥4.5:1，最低一项为浅色三级文字 4.55:1，由 `resolve-tokens.py` 自动校验。

|---|---|---|---|---|
| display | 26 | 33 | 700 | -0.02em |
| title（顶栏） | 21 | 28 | 600 | -0.02em |
| heading | 17 | 24 | 600 | -0.01em |
| bodyStrong | 15 | 23 | 600 | -0.01em |
| body | 15 | 26 | 400 | 0.01em |
| bodyQuiet | 14 | 22 | 400 | 0.01em |
| caption | 12.5 | 18 | 400 | 0 |
| mono | 13 | 20 | 400 | 0 |

- 中文正文必须绑定 Noto Sans SC 子集（仓库既有 `ui_noto_sc_*`），不回退系统字体。
- 人物名与日记标题用衬线，承担"人物感"，其余一律无衬线。
- 行高用绝对值，与 Compose `TextStyle.lineHeight` 一一对应，便于 CI 机械比对。

## 5. 几何与间距

- 圆角：8 / 12 / 16 / 24（面板 16、浮层 16、Sheet 24、控件 12）。
- 间距：4 / 8 / 12 / 16 / 24 / 32 / 40；页面左右边距 24；分组间距 40。
- 命中区 ≥48dp；相邻可点元素间距 ≥8dp；320dp 下输入区次要动作收为横向滚动 chip。

## 6. 界面结构

**会话**：顶栏仅标题 + 状态副标题 + 一个动作；正文全宽无容器，段落/列表/引用/代码各一套排版；代码块带文件名头；元信息与操作行在正文之外；运行中在顶栏下方一条 2px 扫光。

**工作**：目标标题 → 细轨时间线 → 状态色条 → 成果文件行；审批用「去确认 / 忽略」双按钮；引导与停止为行内文字动作。

**能力中心 / 定时任务 / 工作区 / 设置**：同一套无分隔线列表；设置按四组分组（外观与体验 / 模型与账户 / 能力与权限 / 系统）；危险操作在末尾且只用文字色。

**人物图集 / 人物日记**：人物卡为 1:1 相片 + 衬线名字 + 身份，右上角人物色点，选中态为 1px 强调色描边；日记行距 1.9，只此一处把密度放到最低。

## 7. 落地路线

| 阶段 | 内容 |
|---|---|
| P0 | 令牌落地：`SyColors` / `SyMetric` / `SyMotion` + 新增 `SyType`；三主题可回退；八色卡换值保留 key；状态改 phase 枚举驱动（不再靠中文文案判定颜色） |
| P1 | 外壳：透明顶栏、无缝输入底栏、行列表（无分隔线）、设置分组；统一 `pageGutter` / `sectionGutter` |
| P2 | 会话流：正文排版、代码块、引用、消息操作行、扫光进度 |
| P3 | 工作时间线：细轨、状态色条、审批与成果行 |
| P4 | 人物与日记：人物卡、身份色、日记排版 |
| P5 | 浮层与无障碍：menu / sheet / dialog 三变体、减少透明度与减少动效策略、320dp 与 200% 字体复核 |
| P6 | 自动回归：对比度矩阵、令牌与实现同步校验、视觉冒烟 |

## 8. 验收

- 三主题 × 表面 × 三级文字对比度自动通过（≥4.5:1）。
- 320 / 360 / 393 / 412dp 与 100% / 150% / 200% 字体下无截断、无重叠。
- 减少透明度、减少动效下层级与可读性不降级。
- 七条主路由与 21 项设置入口全部可达，行为与现状一致，**视觉重做不夹带功能变更**。
- `tokens.json`、Compose 实现、设计文档三处一致，CI 可校验。

## 9. 明确不做的事

- 不改业务契约、不增删功能入口、不恢复已退役入口。
- 不动用户已有外观偏好数据（色卡 key、主题、字号字重设置全部保留）。
- 不新增字体资源（用仓库既有 Outfit + Noto Sans SC 子集）。
- 不声称已同步 Figma / Canva。
- V7 / V8 的视觉结论不再作为实现依据。
