# 上传设计的原生 UI 重做

本轮权威输入：`shenyan-final.zip`（补齐源码）+ `777-design-v1-2.zip` + `777-design-v1-preview-3.zip` + `index-1.html`。后者与补齐包 HTML 页面结构一致；补齐包新增实际存在的 23 个 Compose 文件及更多预览。旧 APK 复刻记录和上一轮换肤不能作为本轮页面完成证据。

原生继续使用当前 Compose 技术栈和 Feature API。手机按设计 `<600` 的单栏、抽屉和右栏进入 Sheet 的规则实现；保留各页面信息组织、主操作、状态、返回及交互。读取真实数据，禁止把样例计数、费用、进度、连接或亲密度伪装成业务事实。

源码和设计意图有冲突时，以 HTML／预览／手册表达的可见效果为准：给整个卡片 `blur` 会模糊正文，不能当作背景模糊实现；示例重复声明 Mono 名称、缺失 import、无手势的 Sheet 不直接照抄。沿用可运行的原生契约，保留 48dp 触控目标、字体缩放与系统返回。
