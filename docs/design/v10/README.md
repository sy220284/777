- [八页面可交互原型](777-V5.6-交互原型.html)：下载后在浏览器中打开，支持聊天、工作、能力、任务、文件、人物、设置、权限，以及亮暗模式、320/390/430 宽度和 100/140/200% 文字放大；可体验导航、搜索、消息发送、状态切换等。
