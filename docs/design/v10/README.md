## 设计审查重点

1. 在相同任务和内容下比较三种**结构不同**的视觉方向，默认推荐 ORBIT 行动轨迹，须经审美评审。
2. Chat 与 Work 保持功能区分；Work 以目标→过程→交付为核心；工具、任务、设置、人物拥有各自布局。
3. 保留原生权限引导、系统返回、输入法、调度器状态和 Feature 所有权；视觉升级不更改数据与后端协议。
4. 视觉验收与真实 Android 行为回归两条路径独立进行。当前 HTML 原型及其浏览器截图合格，尚未完成 Compose 生产改版。

## 生产实施边界

当前 PR 仅提供设计方案和独立预览 HTML，不修改生产 Kotlin/Compose 行为，也不触发自动化任务、构建或发布。后续重构须以真实 Android 截图、长中文、200% 字号、设备安全区、权限状态和全部功能链路完成验收。
