# 777 移动端参考 APK 对照验收表

## 参考与边界

参考为用户上传的移动端 APK 3.1.3 安装包及设置、侧栏、会话加号、插件、定时任务五类实际截图。本表按照 777 当前业务入口和 Compose 实现逐项审视操作结构，保留 777 自有的业务与权限约束。

**验收事实**：参考截图与 APK 文件可供静态核对；本轮没有在同一台设备上自动化操纵参考 APK 和 777 进行逐屏录屏 / 像素比对。因此所有“已改”的条目都只表示代码提交，不等于视觉或设备验收通过。

## 固定回归规则

1. 每个入口核对默认状态、加载状态、空态、错误态、成功态，以及点击/长按/滑动/返回/遮罩关闭。
2. 操作菜单靠近触发项；多选、列表筛选和长表单分别使用适当的容器；不为迁就统一组件而破坏原操作位置。
3. 操作成功由真实后端结果驱动；不得用 UI 假成功代替业务完成。
4. 页面用实机同尺寸截图检查：顶栏、边距、图标、分割、文字层级、底部固定按钮、系统导航区域与键盘。
5. 每次提交先通过静态、架构、单测和构建，再验 Android 16 / 17 交互；最终验收前 PR 保持 Draft。
