## 二、最终页面交互方案

### 1. HOME：聊天 / 工作合流
- 主界面使用顶部菜单打开侧栏，主背景、顶栏和侧栏连续；不保留主界面三选导航及重复搜索。Chat/Work 模式切换不无故跳出当前设置/功能页；历史会话需用户明确选择才打开。
- Chat：助手阅读宽度 91%、内边距 16/13dp，保留单次换行；消息操作置于正文下方、用量视觉降权；完整回复下方独立“创作”按钮转入多模态面板，点击**不**自动提交收费请求。
- Work：同一消息时间线展示真实执行、计划审阅、问题、审批与成果；**不要**五阶段上方导航、独立产出大卡、重复“新会话”标题。运行中且存在草稿才展示可关闭“立即调整”，默认排队发送仍有效。
- 底部加号为“拍照 / 图片 / 文件 / 多模态创作”四项紧凑入口；同源背景而非白色卡片套卡片；窄屏下图标、菜单/输入/按钮不挤成竖排。
- 输入/输出区不得虚构正在运行、媒体生成百分比、用量或完成验收；未知收费结果禁止盲目自动再提交。

### 2. 侧栏与会话
- 侧栏搜索、当前人物/模式、历史会话、功能入口按真实目标导航；子页面逐级返回，滑动关闭/系统手势与返回栈不冲突。
- 会话行默认无大色块，只有当前/选中轻标记；**删除左滑删除手势**，保留长按的重命名、置顶、多选和需确认的删除。#701 的“左滑按钮藏好”仅是过渡史。
- 不恢复已经废弃的工作项目、独立运行中心、后台助手、沉浸阅读、主界面重复三选项等入口。

### 3. 人物 / 群聊 / 手记
- 人物图集采用单列紧凑头像行，人物资料/故事/编辑可继续查看；不恢复历史数字徽章和逐项阴影卡。
- 人物新建编辑优先直观显示已有字段，提供一个自由补充入口，AI 生成保留未保存草稿和来源；人物预设与旧字段数据的**不兼容变更**不能通过界面伪装已迁移。
- 群聊成员搜索、选择数量和确认真实有效，未选中项不叠加背景阴影；日记以“人物手记”的人物主观心声阅读为主，客观来源、隐私与纠正入口按需展开。

### 4. 工作区 / 任务 / 工具
- 工作区保留文件检索、打开/预览与会话成果回跳，历史/成果版本关联只是来源证据，不自动代表验收。
- 自动化任务保留列表、编辑、暂停/恢复/取消/立即执行；按钮状态和提示必须来自真实受理/拒绝/异常/未知结果。
- 工具、技能、插件：紧凑 40dp 图标、标题、最多两行概述、独立操作行；安装/更新不清空已存在内容，详情保留全文，可用性与失败原因不能隐藏。大字体、窄屏不形成竖排畸形卡。

### 5. 设置 / 模型 / 用量 / 外观
- 设置入口以四类清晰分组组织，二级页面按 21 个实际 `SettingsDestination` 目的地各自表达，不能把不同真实页面合成无功能的样板屏。
- 模型列表与账户接入区分；模型数量放列表标题，不在连接测试旁重复展示；聊天顶部不常驻套餐说明/用量按钮。旧套餐额度查询和已保存模型配置仍按真实业务保留。
- 外观是开放式分组，取消大面积“体验演示套娃”；高级外观默认折叠，包含色彩与背景、材质透明度、动效动画、组件视觉。复杂壁纸需要动态取色与文字对比，透明度调节必须真有效。
- 用量与统计保持真实模型、日期、费用、历史详情和数据状态，但图表与计数指标不再多层大卡套叠。
