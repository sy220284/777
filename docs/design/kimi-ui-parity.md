## 实现与验收范围

| 页面 / 状态 | 参考结构 | 777 的实现与实际能力 |
|---|---|---|
| 侧栏 | 应用身份、直接功能入口、简洁历史、底部搜索与圆形操作 | Chat / Work 模式仍独立；功能移至历史之前；历史保留标题、置顶、多选、重命名和删除；主页面随侧栏位移 |
| 设置 | 中性底色、白色大圆角分组、圆形返回、整行点击 | 账号独立入口；通知、外观、语音与功能设置复用原状态；系统授权另有明确入口 |
| 首页空态 | 居中图形与欢迎语，低密度入口 | 使用 777 自身标识；建议通过菜单选择并写入当前会话草稿 |
| 附件面板 | 横向来源卡片、插件、技能、搜索状态 | 拍照 / 照片 / 文件真实导入；插件与技能进入清单；777 扩展操作可展开 |
| 键盘加号菜单 | 锚定输入框的菜单 | 编辑时展示来源与能力菜单；不强制关闭键盘 |
| 插件 | 搜索胶囊、横向中性分类、白色列表、使用按钮 | 来自实际本机插件与远程连接；不虚构服务商店；使用带着能力标识填入工作会话草稿 |
| 技能 | 独立能力清单与使用入口 | 读取原 workspace 中已安装技能及 front matter；禁止模型调用的技能不提供自动使用入口 |
| 任务空态 | 中心插图、底部双按钮、右上创建菜单 | 手动创建进入编辑器；对话创建携带任务需求提示进入工作会话；无绑定会话的宿主不展示无效按钮 |
| 任务详情 / 编辑 | 层级分明的详情与编辑流程 | 简洁列表进入详情；完整执行记录、编辑、运行、暂停 / 恢复和删除沿用 Automation 所有权；保存固定在底部 |
| 时间选择 | 与应用一致的选择浮层 | 日期、时间与静默时间使用 Compose 面板；未来时间校验保留 |
| 文件 | 按格式区分图标 | APK 的 PDF / Word / Excel 明暗图标对应真实扩展名；代码、图片、文本继续按实际格式显示 |

## 不能用外观代替的状态

- 插件和技能通过工作会话执行；从聊天选择这些能力时明确进入工作模式，并保留原聊天及草稿。聊天联网仍沿用最新 main 的联网上下文实现。
- 插件选择与任务对话创建只填入工作会话草稿，由用户补充并发送，不偷偷自动执行。
- 附件使用现有导入与去重 / 图片数量限制；拍照回调绑定发起会话，取消、失败或切换会话后清理临时文件。
- 777 没有参考产品的订阅商店或微信文档直连，不添加空壳商店与不可执行入口。
- 任务没有独立的名称 / 每任务模型字段，展示真实任务 prompt 与现有模型执行配置，不保存 UI 自造字段。
- 已有工作动画资源与运行状态绑定保持在原执行投影中。

## 验证

本轮使用 main 最近成功的 dev-toolchain 工件离线构建：`:app:assembleDebug`、`:app:assembleDebugAndroidTest`、`:app:testDebugUnitTest` 全部通过。已合入 main 的联网搜索与月度排程修正后重新验证：297 个套件、1,852 项单元测试，失败和错误均为 0。新增的插件清单及工作模式确认 Compose 回归已编译，尚未在设备上执行。

架构、设计系统、UI 文案预算、安全、性能不变量、Kotlin 风险模式、测试质量与构建基线检查通过。Android 16 模拟器没有硬件加速，完成启动后在安装期间会话中断；尚未取得本轮运行截图，因此像素、键盘定位、滑动动画和完整交互仍待设备验收。不能把 APK 构建成功当作视觉一致性通过。Android 16 / 17 的设备测试以该 PR 当前提交对应的 CI 为准。
