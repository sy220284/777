# 设置、侧栏与消息操作精修

本次按用户确认范围执行，保持现有浅灰白底与单色线性图标语言。设计图属于效果示意；人物、系统状态栏和真实运行状态以应用为准。

## 设置首页

设置首页归并为三个分组，全部原入口保留，点击和返回链路不变：

| 分组 | 入口 |
| --- | --- |
| 常用 | 账号、通知、外观与阅读、会话 |
| 模型与体验 | 模型设置、模型价格与消耗、个性化与记忆 |
| 系统与维护 | 连接与权限、高级、检查更新 |

分组标题放在卡片外。首页卡片使用 18dp 圆角，列表行最小 56dp、图标 22dp、文字 16sp，中长内容允许扩展高度。返回按钮取消常驻白色圆底，点击范围继续为 48dp。子页面沿用已有组件尺寸。连接与权限将孤立状态点改为来自真实设备能力状态的“待配置／已就绪／检查失败／加载中”文字。

## 侧栏

原布局、宽度、位置、间距、搜索、新建、模式切换、历史排序、选中背景和底部圆形按钮保持。只调整字重和底部图标：应用标题与当前会话半粗，功能入口中等，普通历史会话与分组标题常规。所有字重继续尊重用户阅读偏好。

远程控制使用屏幕配连接标记，设置使用闭合齿轮轮廓；两者均为 24 单位网格的单色线性符号，点击含义和无障碍名称不变。

## 消息操作

参考用户提供的回复工具栏：复制与重试无文字、无底色、无边框，使用灰色圆头线性图标。可见图标从 18dp 提升为 22dp，点击范围继续为 48dp。复制使用圆角双页，重试使用单环箭头。复制成功短暂显示对勾，同时沿用原复制反馈。

复制仍只复制用户可见的回复，重试仍调用当前重新生成入口，生成状态、取消与分支切换规则保持。动作无障碍名称保留，禁用态继续区分。聊天正文、头像、用户气泡、顶栏和输入区布局不在本次改动范围。

## 验证

复查十项设置入口、权限状态、子页返回、侧栏 Chat/Work、选中会话、复制、重新生成、分支切换、长文本和阅读偏好。按 VALIDATION.md 执行静态门禁及完整产品 CI；构建与设备验证通过前，不将效果图当作实际 APK 验收结果。
