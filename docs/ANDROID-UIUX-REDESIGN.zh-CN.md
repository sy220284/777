# 777 安卓界面与交互改版

## 产品主线

```text
启动 → 本机会话 → 输入目标 → 查看过程与结果
             ├─ 审批 / 回答提问
             ├─ 查看文件与产物
             └─ 切换会话、任务、工具、设置或远程控制
```

本机运行是首页；远程控制是另一种运行方式。用户需要持续知道当前在**哪个会话**、**手机还是远程在执行**、**是否需要自己处理**，同时能迅速回到输入和结果。执行轨迹、模型配置、权限和高级工具按使用频率逐层展开。

## 界面规则

| 区域 | 主信息与操作 | 展开后可见 |
| --- | --- | --- |
| 顶栏 | 会话名称、运行位置和状态；新建会话 | 模型与密钥配置、会话列表 |
| 对话 | 用户请求、助手结论、可折叠的工作过程 | 工具输入输出、轨迹 |
| 阻断操作 | 审批和提问保持在输入区附近 | 详细原因与选项 |
| 输入区 | 草稿、附件、规划开关、发送或停止 | 图片与文件选择、其他能力 |
| 侧栏 | 新会话、当前会话、历史会话、运行方式 | 任务、工具与连接、设置、工作区文件 |

## 这轮落地

1. 本机页头以会话标题为主，明确显示「本机 · 执行中／等待批准／等待回答／已就绪」；新建、文件在顶栏，模型配置在完整可点的下一行，窄屏仍能看清标题。
2. 本机侧栏提供固定的新会话入口，运行方式同时列出本机和远程；历史会话继续可搜索。
3. 空会话用纵向示例展示真实能力和审批预期，窄屏中保持完整可点区域；示例按界面语言填入草稿，用户仍决定是否发送。
4. 远程页头将模型切换和文字状态放到第二行，长会话标题在窄屏仍可读；模型切换区达到 48dp 最小触摸高度。
5. 自动批准提示缩成可展开的状态行，授权范围仍可随时查看，关闭按钮始终可见。

## 后续衔接与验收

- 工作区文件和单轮产物入口由文件功能改动承接；合并时保持会话顶栏与侧栏的层级，不覆盖文件入口。
- 横屏和分屏的边界适配由对应改动承接；本轮代码保持标题单行截断、纵向可滚动列表、固定输入区。
- 验收至少覆盖：320dp 宽度、大字号、输入法展开、长会话标题、空会话、运行中、审批待处理、浅色和深色模式、本机与远程切换。
- Android 官方建议按窗口宽度调整导航形态，交互目标至少 48dp：
  [导航与布局](https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-and-nav-patterns)、
  [无障碍触摸目标](https://developer.android.com/guide/topics/ui/accessibility/apps)。
