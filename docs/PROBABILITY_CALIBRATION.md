# 红球概率校准探索结论

## 目标

验证 V4 输出的红球分数能否校准成真正有预测意义的概率，并进一步改善候选池与实际奖级。原则是：概率数值更“好看”不算升级，必须最终改善选号。

随机基线为每个红球下一期出现概率：

`6 / 33 = 18.1818%`

## 结果一：原始概率没有优于恒定随机基线

从 seq=751 到 seq=3501：

- 恒定18.18%基线 Brier：`0.14876033`
- V4全历史子模型：`0.14883808`
- V4 1000期子模型：`0.14888582`
- V4 500期子模型：`0.14900484`

新增55期独立前向段更弱：三个子模型 AUC 分别约 `0.488 / 0.477 / 0.451`。

结论：V4当前真正可能存在的价值是很弱的相对排序信息，不是原始概率值本身。

## 结果二：按历史排名位置做因果概率校准

每期开奖前，根据此前历史中“模型第1名、第2名……第33名”的真实命中率进行强收缩校准。

该方法能让概率值更接近18.18%的长期基准，但会削弱长期候选池：

- V4原前12：全量平均命中 `2.2221`，含4+ `338期`，含5+ `46期`
- 100期校准：平均命中约 `2.1803`，含4+ `295期`，含5+ `42期`
- 250期校准：平均命中约 `2.1654`，含4+ `275期`，含5+ `38期`

因此它适合作为“概率可信度诊断”，不适合替换号码排序。

## 结果三：让校准真正改变号码排序

尝试对每个号码的历史系统性偏差进行强收缩修正。代表方案：

- 200期窗口、10%修正：前12含5+略升，但接回V4.5组合层后四等奖 `13→8`，固定回报 `4780→3770元`
- 250期窗口、10%修正：接回组合层后四等奖 `13→10`，固定回报 `4780→4145元`

说明“候选池某一局部指标增加”没有转化成实际奖级收益。

## 决策

1. 概率校准工具保留，用于判断模型是否过度自信、概率值是否可信。
2. 不把校准后的概率接入当前生产选号链。
3. V4.5.1继续作为当前研究主版本。
4. 后续不继续围绕校准窗口、收缩强度做参数挖掘。
5. 下一阶段转向低成本独立信息源；任何新信息仍需先通过候选池和随机对照，再看实际奖级。

机器可读结果：`backtests/v4_5_1/probability_calibration_summary.json`。
工具：`tools/probability_calibration.py`。

> 结论只说明当前历史和当前模型下的统计表现，不证明彩票开奖存在可稳定利用的规律。
