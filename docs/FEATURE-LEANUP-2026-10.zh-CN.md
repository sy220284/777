# 777 退役功能与体验收敛记录

## 原则
仅移除没有运行消费或已有等效入口的功能。聊天与工作核心能力、数据恢复、安全校验和自动调度不随 UI 收敛而删除。

## 处理
- 会话排序：移除无效的手动排序开关，会话抽屉保持按更新时间排序；迁移时清理失效偏好。
- 自动任务建议：清除任务页独立的进页模型建议请求、UI、状态与解析器。保留用户显式发起的自动任务规划、编辑与创建。
- 用户下一句回复建议：在已有用户主动点击生成的建议中，允许基于真正存在的未来事项推荐后续互动或提醒话术；未出现未来安排时保持普通接话建议。不自动创建定时任务。
- 群公告：保留用户手动编辑及将背景送入群聊上下文，移除独立 AI 公告生成器及其固定剧情模板。
- 研究代理：移除与普通只读后台代理仅有固定提示词差异的专用入口及预设；研究类任务仍可交给普通后台代理。
- 旧协议：清除无现行消费者的远程主机、旧命令、凭据、代理预设、目标、插件清单及面板 DTO。现有本机模型、工具和工作协议照常使用。
- 旧网页终端：移除无 UI 消费者的 xterm 静态资源及许可声明，保留 Android 本机终端能力。
- README：撤下无现行实现的旧消息反馈能力宣称。
- 高级能力：Webhook、手动团队管理、细粒度用量与诊断保留，但应避免侵入日常主流程。

## 回归重点
1. 会话历史仍按更新时间排列，旧排序项退出设置，迁移不丢失其他偏好。
2. 进入自动任务页面不发起单独的建议模型请求；新建、优化、编辑、暂停和执行正常。
3. 下一句建议只有用户主动点击才生成；包含未来约定时可建议用户表达提醒和再次联系，不能伪称任务已创建。
4. 群公告保存、跨会话恢复和群聊上下文引用不变。
5. 普通后台子代理仍可执行只读调研和文档阅读，研究专用开关消失。
6. 编译、单元测试、Android UI 回归和旧资源引用检查通过后合并。
