# 功能树维护已退役

自 PR #895 起，777 **停止维护功能树及其源码证据/验收索引**。同步工作流、生成和检查脚本，以及 CI 中的功能树门禁和证据上传链路全部退出。

旧的 `FEATURE-TREE.zh-CN.md`、交互 HTML、各类 `FEATURE-*.auto.json`、`ACCEPTANCE-MATRIX.json` 与来源证据文件保留为**历史冻结快照**，不再自动更新，不作为当前功能范围、代码入口、功能完成度或 CI 合并条件。

今后功能的事实与交付以以下依据确定：

1. 当前分支或主线实际生产代码、组件注册和用户可操作入口。
2. 当前 SHA 的有效单元测试、Android 构建及需要的设备回归。
3. 功能调用产生的真实状态、错误、日志与最终用户结果。
4. 对应权威架构、接口协议和专项验收文档。

历史文件需要查询时可直接读取，但不要求开发人员维护它们，不触发任何独立定时任务、工作流或 CI 检查。
