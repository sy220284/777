## 结构与横纵链路

- 工作链路：会话菜单 → Feature UI actions → Harness ViewModel → WorkRuntime → 同一 EventLog／工作区；UI 控制器只拥有游标、加载、选择和错误，不另存工作业务事实。关闭弹层取消其读取协程。
- 记忆链路：Settings UI → 请求控制器 → Settings facade → MemoryStore。搜索在事实源分页之前发生，修改与停用继续通过既有写入及日记失效处理；请求换代后丢弃迟到读取。
- 自动化链路：Chat／Work UI → TasksViewModel → 原 Scheduler／任务存储。操作回执与实际执行状态分离；“立即运行已提交”不冒充“任务已经完成”。本轮异步改造针对上述四类管理命令，创建／编辑仍沿用既有契约。
- 文件链路：EventLog 确定来源，文件系统提供当前可用性，显式 SHA-256 核验确定内容版本。日志重置或来源身份变化后，旧选择不能继续写入新日志。
- V6 保留现有七条路由，通过会话内弹层接入能力；同步当前 UI 清单、状态台账、可编辑 JS 和离线 HTML，不恢复独立运行中心或项目管理旧入口。
