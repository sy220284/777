# 777 移动端 UI：按使用频率重构方案

> 基线：0.12.0-777.11  
> 目标版本：0.12.0-777.12  
> 设计方向：Kimi 式轻量移动交互 + Harness 专业能力按需展开

## 1. 核心结论

777 的功能量已经超过普通聊天应用，继续把能力平铺在聊天页会导致“功能越完整，主界面越像控制台”。

本轮采用“频率优先 + 任务优先”的信息架构：

```text
777
├─ 第一层：每轮都可能使用
│  ├─ 新建 / 切换会话
│  ├─ 当前会话
│  ├─ 模型切换
│  ├─ 输入
│  ├─ 附件
│  └─ 发送 / 停止
│
├─ 第二层：按场景频繁使用
│  ├─ 权限
│  ├─ 搜索会话
│  ├─ 工作区
│  ├─ Goal / Todo / Queue
│  └─ 运行详情
│
├─ 第三层：专业但低频
│  ├─ Agent preset
│  ├─ Subagent
│  ├─ Trajectory
│  ├─ Token / Context / Timing
│  ├─ Commands
│  └─ Skills
│
└─ 第四层：管理与诊断
   ├─ 本机 / 局域网 / 中继
   ├─ 网络诊断
   ├─ 环境能力
   ├─ 通知
   ├─ 数据
   └─ 设置
```

规则只有一条：**频率越高，距离拇指和主任务越近；频率越低，越不能长期占用聊天内容面积。**

## 3. 页面结构

### 3.1 聊天页

旧结构包含多层顶部栏、永久 Chat/Trajectory 切换、永久工作区入口、永久统计脚注。

新结构：

```text
┌─────────────────────────────┐
│ ☰  会话标题                 ⓘ │
│    模型 ▾                 ●   │
├─────────────────────────────┤
│                             │
│          对话内容            │
│                             │
│  Todo / Goal / Queue（按需） │
│                             │
│  ┌───────────────────────┐  │
│  │ +  输入内容        ↑  │  │
│  │    权限/上下文          │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

顶部只保留：会话抽屉、会话标题、模型、运行中指示、详情。

移除常驻：Agent preset、Subagent、Chat / Trajectory 标签条、Workspace 文本按钮、Stats footer。

### 3.2 “+”能力面板

顺序：
1. 图片 / 文件；
2. 模型；
3. Agent preset；
4. Subagent；
5. Workspace；
6. Chat / Trajectory；
7. Queue / Steer；
8. Commands；
9. Skills。

高频入口使用大触控块，低频能力使用分组列表。

### 3.3 会话侧栏

旧顺序：

```text
品牌
本机 Harness / 设置
会话
新建工作区
搜索
```

新顺序：

```text
品牌 + 新建会话
搜索
会话 + 排序
会话列表
新建工作区
本机 Harness / 设置
```

## 4. 视觉调整

- 页面底色：`#F7F7F5`；
- 功能块底色：`#F2F2EF`；
- 白色卡片保持纯白，形成轻浮层；
- 输入框阴影从 8dp 收到 6dp；
- 顶部栏从多层压缩为单层信息结构；
- 模型切换器缩成 30dp 紧凑胶囊；
- 闲置状态点不常驻，只在运行时显示。

## 5. 不下沉的能力

- 模型：不同任务会频繁切换，保留顶部入口；
- 权限：直接影响工具执行，保留输入区；
- Approval / Ask User / Plan Review：会阻塞当前 turn，直接出现；
- Goal / Todo / Queue：存在时就是当前任务上下文。

## 6. 验收标准

- 顶部常驻高度不再随 preset / subagent / trajectory 增长；
- Workspace 不再永久占用聊天正文；
- Stats 不与详情面板重复；
- 模型最多两次点击完成切换；
- Trajectory、Preset、Subagent、Workspace 最多两次点击可达；
- 打开侧栏无需滚动即可看到搜索；
- 会话列表获得更高首屏占比；
- 本机 Harness / 设置仍可达，但退出首屏黄金区域。

## 7. 本轮实现映射

- `ChatTopBar.kt`：顶部结构收敛；
- `ChatScreen.kt`：去掉低频常驻入口；
- `SheetCommands.kt`：升级为统一会话能力面板；
- `ChatListDrawer.kt`：搜索上移，管理入口下沉；
- `Color.kt`：浅色主题改暖中性画布；
- `Composer.kt`：输入区阴影减轻；
- `app/build.gradle.kts`：版本推进至 `0.12.0-777.12`。
