# V4.5.1 可预测性信号门控

## 为什么只做这一处改动

V4.6已经验证：加快重训练、快慢切换、池内重排和加强正则化都没有同时改善旧历史奖级与新增55期前向表现。因此本轮不增加新模型，只回答一个更基础的问题：**当前V4候选池是否仍然表现得比随机选择12个红球更好？**

随机12号池每期平均应包含 `6×12/33 = 2.181818` 个真实红球。V4.5.1在每期开奖前，只统计过去250期V4前12候选实际包含的红球数：

- 滚动均值 ≥ 2.181818：允许使用V4.5高奖集中组合；
- 滚动均值 < 2.181818：视为近期未观察到足够候选池增益，回退V4.3分散组合。

窗口250期与现有V4训练块一致，不新增需要调优的复杂层级。最初50个盲测点默认回退V4.3。

增益很小，但没有靠新增复杂模型获得。

### 新增55期独立前向段

- V4.5：6注六等奖，固定回报30元；
- V4.5.1：**9注六等奖，固定回报45元**；
- 两者都没有出现四、五等奖，因此不能宣称高奖预测能力得到独立确认。

### 四个连续分段

相对V4.5固定奖金变化：`+10 / -10 / +15 / +10` 元。没有出现某一段巨大提升撑起总结果的情况，但幅度仍然属于弱增益。

## 打乱历史检验

使用2000次时间顺序打乱，保持每期号码集合及总体边际频率不变，只破坏“预测分数与真实开奖的时间对应关系”。V4前12结果：

- 平均命中：真实2.2221；打乱均值2.2091；`p≈0.2455`，不显著；
- 含4+：真实12.286%；打乱均值11.372%；`p≈0.0595`，接近但未达到稳固证据；
- 含5+：`p≈0.5355`，无时间信息优势；
- 含6：`p≈0.26`，无稳固优势。

因此当前不能把V4.5.1描述成“发现了可预测规律”。它的作用是：**当既有候选池近期连随机基准都没有超过时，主动停止高集中下注。**

## 结论

V4.5.1可以晋级为当前研究版，因为它满足三个条件：实现简单、长期奖级不退、新增55期前向表现改善。但提升幅度很小，下一阶段仍应优先寻找真正能够提升前12含5+概率的信息，而不是继续微调这个门控窗口。
