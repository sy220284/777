# V4.2 优化说明

## 目标

V4.2 不再把“多覆盖号码”当作唯一目标，而是同时追求：

1. 01-33逐号概率排序尽量准确；
2. 已进入前12候选池的真实号码，尽量集中在同一注；
3. 最终以双色球真实奖级，而不是平均红球命中数，作为主验收指标。

## V4.1 特征消融结论

对极短期频率、结构身份、遗漏、共现等特征组进行了滚动消融；去掉5期/10期短窗后，部分候选池指标改善，但端到端奖级没有同步改善，因此生产红球排序保留V4全特征版本。非线性树模型在Top10/Top12和留出段上退化，未采用。

蓝球简化模型将Top1/Top2历史命中率提高，但与红球高命中期同步性下降，使四等奖以上结果变差，因此最终仍保留V4蓝球基线。局部指标不能覆盖最终奖级目标。

## V4.2 联合概率分组

V4的问题不是完全找不到号码，而是正确号码经常分散在两注中。V4.2因此保持前12候选池不变，只优化这12个号码如何分成两组六码。

对目标期之前最近500期统计号码对共现，使用边际频率修正后的标准化残差作为号码对亲和度。前12号码共有462种不重复的6+6分区，模型选择组内总亲和度最高的分区。

为避免随机共现被强行使用，增加因果门控：只有本期最佳分区的置信度不低于此前250期置信度中位数时，才启用联合聚类；否则回退V4原始1-6/7-12拆分。整个门控不读取目标期开奖结果。

## 盲测结果

同一2696期严格滚动盲测：

| 指标 | V4 | V4.2 |
|---|---:|---:|
| 四等奖 | 5 | 7 |
| 五等奖 | 49 | 57 |
| 六等奖 | 337 | 328 |
| 未中奖 | 2305 | 2304 |
| 固定奖金回报 | 3175元 | 3610元 |
| 固定回报率 | 29.44% | 33.48% |

V4.2没有出现一、二、三等奖，因此不能宣称高奖预测能力已经成立。当前改进主要体现在把低价值的零散命中向四、五等奖集中。

前后各1348期验证中，V4.2相对V4都提高了四等奖、五等奖和固定奖金回报，没有出现只在开发段有效、留出段反向失效的情况。

## 下一步

下一版本优先研究三件事：

1. 把两两联合概率扩展到三元组合，但使用强收缩和最小样本门槛；
2. 对候选池进行概率校准，验证Top8/Top10/Top12是否真正压缩结果空间；
3. 动态胆码只在“核心号置信差距 + 历史前向增益”同时成立时开启，不固定共享号码。

任何新增因素如果不能在前后时序段同时提高真实奖级，都不进入生产模型。
