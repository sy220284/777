1. 320dp/390dp，字体 1.0/1.3/2.0：重要标题、操作、数值完整可达。
2. 输入法可见时输入与提交不遮挡，Sheet 长内容可滚动，主动作可达。

5. 浅深主题、极端壁纸和减少动态效果：阅读与反馈一致。
