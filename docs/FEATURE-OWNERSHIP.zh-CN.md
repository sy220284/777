# 777 功能归属与新增能力整合准则

> 本文记录现有功能与 #513—#517 集成后的逻辑归属、入口和唯一事实源。架构约束仍以 [架构 3.0](ARCHITECTURE.md) 为准。本整合分支须以最新代码的完整 CI 与 Android 设备测试结果验收。

| 归属 | 已有及新增能力 | 入口与行为 | 事实源 |
|---|---|---|---|

| WorkFeature | 工作会话、规划、Todo、目标、审批、提问、后台子代理、智能体团队/集群、资料研究预设、运行中心、工具活动和工作成果展示 | 工作主界面加号调用 Agent 团队；运行中心查看任务、工具与成果 | Session EventLog / 共享 Agent / Tool 运行链 |
| ProjectFeature | 项目列表、创建切换、长期指令、会话项目归属 | 项目管理入口；工作空间仍管理真实文件 | 项目仅持有身份、名称和指令，Session / Memory / Files 各持有其记录 |

| SettingsFeature | 模型/账户、记忆管理、外观、审批策略、用量、诊断 | 设置菜单及对应二级页面 | 配置由实际所属 Feature 或共享能力持有，设置仅作入口 |
| Shell | 主界面、侧栏、会话导航、聊天/工作切换、统一 Sheet/弹窗 | 统一会话主界面与 + 面板 | Shell 只负责 UI 宿主及路由 |

## 不新建平行系统

- **研究代理**：以 Work-owned 预设启动已有 Subagent；稳定身份指令不放大工具权限。
- **Agent 集群**：复用现有 Lead、Teammate、任务依赖图与持久恢复；运行信息投影到主会话，详情归运行中心。
- **工作成果**：只从真实且成功的 Session EventLog 工具事件提取；不新建成果数据库，不把执行失败、无效路径当成成果。
- **工具活动**：只消费 Shared Tool Activity / Session EventLog 公开只读投影，不复制执行事实。
- **记忆空间**：以 MemoryStore 为唯一事实源，按全局/项目/对话链和类别只读分组；人物日记保持 Chat 领域规则。
- **自动任务优化**：从当前任务预填原指令、时间与触发条件，复用 Planner 和现有任务更新及用户确认，不建立独立模型服务。
- **插件/技能/联网**：共享工具发现与授权边界；加号与清单只是入口，不再另建能力路由或执行器。
- **附件与文件**：统一消息块与本地文件引用；工作空间持有实际文件，项目只关联身份。

保留统一聊天主界面，按聊天/工作切换。项目与文件、运行中心、定时任务、工具与扩展、设置可在侧栏进入。群聊、人物、日记归聊天领域，Agent 团队从工作模式 + 面板启动；工具活动和成果随真实运行状态展示，界面读取同一份运行记录。
