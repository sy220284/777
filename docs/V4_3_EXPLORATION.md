# V4.3 探索与收敛记录

## 目标

继续围绕“下一期号码排布尽可能准确”推进，但所有新增逻辑必须先回答两个问题：

1. 能否让前12候选池中的真实号码更集中到同一注；
2. 能否在实际奖级上跨时间段稳定优于V4.2，而不是只提高平均红球命中。

## 关键诊断

V4前12候选池在2696期盲测中有335期包含至少4个真实红球，占12.43%；随机12号池的精确理论概率约10.97%。这说明底层候选池存在弱信息，但组合层仍损失了大量可利用的集中度。

同时，V4的第1至12名真实命中率并不单调，部分阶段第8至10名甚至高于第1至3名。因此“排名靠前=可直接当胆码”不成立。

## 本轮探索

### 三元联合概率

测试了300/500/800/1000等历史窗口及不同三元权重。开发段可出现明显提升，但后半留出段同步下降；其中800期窗口甚至依赖单次三等奖事件抬高回报，稳定性不足。结论：暂不进入生产。

### 动态胆码

测试共享1、2、3个头部号码。固定共享均降低整体回报；多模型一致性也未显示“越一致命中率越高”的稳定单调关系。结论：胆码功能继续保留研究，但必须等号码概率校准真正形成分层后再启用。

### 边际概率强聚集

在联合分组目标中加入“把高排名号码放到同一注”的奖励。开发段和留出段方向不一致，权重稍大即出现明显过拟合。结论：拒绝进入生产。

### 多尺度两两联合关系

500期联合关系仍是主信号，但单一窗口对边界较敏感。加入20%的600期弱辅助后，既保留500期响应速度，又对偶然共现做轻量平滑。

### 长窗置信门控

V4.2用最近250期置信度中位数决定是否启用联合聚类，容易跟随局部噪声。延长到600期后，门控更稳定。

最终生产参数：

- 500期联合关系：80%
- 600期联合关系：20%
- 置信门控历史窗口：600期
- 门槛：过去窗口中位数
- 前12候选池保持不变，仅优化6+6分组

## 盲测结果

同一2696期严格滚动盲测：

| 奖级 | V4.2 | V4.3 |
|---|---:|---:|
| 四等奖 | 7 | 8 |
| 五等奖 | 57 | 60 |
| 六等奖 | 328 | 327 |
| 未中奖 | 2304 | 2301 |
| 固定回报 | 3610元 | 3835元 |

固定回报相对提高约6.23%。

四个连续674期分段固定回报：

- 第1段：775 → 770
- 第2段：655 → 670
- 第3段：1225 → 1255
- 第4段：955 → 1140

没有出现依赖单个异常大奖抬高总成绩的情况，但第1段存在轻微退化，因此仍只能视为弱增益，不应宣称已具备稳定预测能力。

## 下一阶段

1. 不再直接增加更高阶共现维度，先提升号码级概率校准，使排名具备真正单调性；
2. 对“候选池含4+真实红球”的事件建立单独判别器，研究何时值得集中而非分散；
3. 动态胆码只有在候选排名分层和历史校准同时过门槛时才开启；
4. 继续使用实际奖级、前后时间段一致性和最新前向数据作为验收条件。
