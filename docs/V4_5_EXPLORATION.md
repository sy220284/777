# V4.5 高奖级集中组合探索记录

## 目标

本轮不再优化“中奖期率”或六等奖数量，固定每期两注预算，直接把目标上移到：三等奖及以上 > 四等奖 > 五等奖 > 六等奖。由于历史盲测中尚未出现三等奖及以上，可验证主指标先以四等奖数量、5红集中次数和固定奖金回报作为代理，同时保留严格的逐期因果约束。

## 关键诊断

V4/V4.4 的前12候选池在2696期中有335期包含至少4个真实红球、45期包含至少5个、4期6个红球全部进入前12。但V4.4最终两注仅出现1次5红，说明损失主要发生在“候选池已经足够好，但正确号码被拆散”。因此V4.5不继续堆逐号特征，优先改组合层。

## 红球：高置信集中投资组合

V4.5保留V4逐号排序和V4.3常规分组作为基线。对前12候选号枚举全部924个6号子集：

- 子集得分 = 组内历史两两联合关系标准分 + 1.25×边际逐号排名和标准分；
- 第一注取最高得分子集；
- 第二注允许与第一注最多重合3个红球，再取约束下最高得分子集；
- 仅当当前集中置信度达到此前800期75%分位以上才启用，否则回退V4.3常规分组。

邻近参数扫描显示，`联合/边际权重1.25~1.5`、`门控分位75%~80%`、`窗口600~1000期`形成连续有效区域，不依赖单个尖点。最终取平台中部参数。

## 蓝球：按实际奖级效用融合

V4.4按过去“前2蓝球是否命中”硬选择子模型。V4.5改为三个蓝球模型连续融合：

1. 1000期完整特征基线；
2. 750期完整特征模型；
3. 1000期频率/趋势/遗漏精简模型。

每期模型权重仅由此前1100期实际奖级效用与前2蓝球覆盖表现决定，再做温度0.75的软融合，并向等权收缩15%。这样避免某个模型短期走强后被100%押注。

## 淘汰路线

- 扩大候选池到14/15：池内5+真实红球次数增加，但从更大池压缩到6号时噪声同步增加，最终奖级不及12号池集中方案。
- 两注共享同一蓝球：六等奖覆盖显著下降，未换来三等奖，淘汰。
- 不同蓝球模型各取第一候选：模型分歧没有形成有效互补，四等奖下降，淘汰。
- 静态固定蓝球模型：不如奖级效用融合。
- 三元联合概率：样本继续过稀疏，沿用V4.3淘汰结论。

## 结论与下一步

V4.5证明“奖级目标函数”比单纯覆盖目标更符合当前任务：它减少部分五等奖/普通覆盖，换来更多四等奖与5红集中。但一、二、三等奖仍为0，不能据此宣称具备稳定预测能力。

下一阶段优先：

1. 用2026-05-03之后新增开奖做冻结前向验证；
2. 针对45个“前12池含5+”历史状态研究可观测的高价值门控特征，但必须防止稀有事件过拟合；
3. 研究基于组合概率的主攻/防守双票非对称目标，而不是继续增加历史派生特征；
4. 如能取得开奖设备、球组批次等独立外生信息，单独建模验证，不与现有历史派生信号混用。

> 历史盲测提升不代表未来可稳定中奖，本项目仅用于统计研究。
