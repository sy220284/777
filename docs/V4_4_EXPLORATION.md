# V4.4 下一阶段探索记录

## 目标

在 V4.3 已确认的“逐号排序 + 多尺度号码对联合聚类”基础上，继续提高实际奖级，而不是优化表面命中指标。

## 本轮验证并淘汰

1. **候选池含4+状态分类器**：逻辑回归判别能力约0.48，树模型约0.49，无法提前识别“前12候选池会特别准”的期次，因此不启用动态胆码。
2. **二级概率校准/三时间尺度重新集成**：对前6局部有时改善，但前12覆盖及留出段不稳定，没有同时超过 V4 基线。
3. **监督式号码对同时命中模型**：直接学习候选号码两两同时命中概率后，开发/留出均未优于 V4.3 的历史共现残差聚类。
4. **模型排名位置共现**：局部参数曾出现一次三等奖，但邻近参数无法复现；按不让单次高奖支配结果的稳健口径低于 V4.3，判定为偶然事件。
5. **继续调整 V4.3 聚类门控**：扫描多个窗口和分位数后，没有配置能在四个连续历史段中稳定超过当前600期中位数门控。

## 保留改进：蓝球双模型因果选择

V4 蓝球基线采用完整特征、1000期训练窗。新增一个750期模型，去掉号码绝对位置和奇偶身份两项容易形成静态偏置的特征，只保留多尺度频率、趋势、遗漏、上期关系和长期频率。

每一期只比较两个模型在此前900期的“前两蓝球候选是否命中”真实表现，选择历史表现更好的模型。平局回退 V4 基线。选择过程严格不读取目标期开奖。

900期不是孤立最优点：800、825、850、875、900、925、950、975、1000期窗口均得到10次四等奖，固定回报约4195—4225元，形成稳定平台。

## 结论

V4.4 只升级蓝球选择层，红球 V4.3 保持冻结。当前证据支持“自适应蓝球子模型选择”进入研究主版本，但仍不构成未来中奖保证。

下一阶段优先级：

1. 用新增真实开奖做冻结前向验证；
2. 研究蓝球子模型选择是否可改为贝叶斯收缩而不是硬切换；
3. 红球继续寻找能直接提升前12含4+/5+率的新信息源，现有历史派生特征暂不继续堆叠；
4. 若能获得开奖设备、球组、机器编号等可靠元数据，再建立独立物理状态层验证。
