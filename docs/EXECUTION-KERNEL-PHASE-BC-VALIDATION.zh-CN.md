# 总控执行内核 Phase B / C 联合验收

本文件记录阶段 B「持久自治」与阶段 C「多智能体执行平台」在当前主线上的最终闭环范围。

## Phase B：持久自治

已完成：

- 普通后台任务快照持久化到应用私有存储。
- 进程退出前处于 `running` 的任务，重启后恢复为 `interrupted`，不会伪装成完成。
- 仅明确声明可安全恢复的任务带 `resumeKind/resumePayload`，可通过 `resumePersistent()` 续跑。
- 网页抓取与只读子代理已经接入安全恢复入口。
- 可能产生未知副作用的普通任务不会在进程重启后盲目重放。
- 上下文预算根据 Android 内存档位和实时资源压力动态收缩。
- 主智能体与子智能体共用历史预算策略。

## Phase C：多智能体执行平台

已完成：

- 统一资源调度覆盖模型请求、智能体、终端、虚拟屏、语言服务。
- 长生命周期资源通过租约持有，结束或异常时释放。
- 子智能体可申请独立虚拟屏，并限制只能操作自己的虚拟屏。
- 本机模型支持流式正文、推理内容和工具调用参数拼接。
- 执行控制台展示智能体、终端、虚拟屏、语言服务与上下文预算状态。
- 资源压力进入上下文预算计算，形成执行资源与上下文治理联动。

## 联合回归门禁

`ExecutionKernelPhaseBcIntegrationTest` 额外验证：

1. 持久任务在重启语义下从 `running` 进入 `interrupted`。
2. 可恢复任务续跑后状态重新持久化为 `completed`。
3. 虚拟屏占满资源预算时，上下文预算会同步收缩。
4. 恢复任务执行结束后 Agent 租约归零。
5. 多层资源租约即使异常退出也不会泄漏。

阶段 B/C 后续修改不得破坏上述行为。
