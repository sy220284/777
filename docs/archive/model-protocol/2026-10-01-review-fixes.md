# 模型配置身份与工具调用完整性修复

## 问题与行为

- Claude 旧模型名称迁移后，同一模型/地址可能对应两个既有凭据 ID。编辑、检测、保存必须传递选中 ID；没有 ID 的重复路由拒绝猜测。选中配置消失、路由变更或凭据丢失时，不读取其他配置的密钥。
- 设置模型列表按活动配置 ID 显示使用状态和切换入口，API Key 与不同 ChatGPT 账户的相同模型/地址不再互相遮挡。保存路由、删除配置、清除凭据、账户同步和会话启动都投影同一模型选择状态。
- Chat Completions 的流式/非流式以及 canonical 历史解析使用同一工具调用校验：ID、名称和参数均为合法非空字符串；参数必须是明确收到的完整 JSON 对象；调用 ID 不得重复。明确的 `{}` 无参调用有效，缺失字段不再被补成 `{}`。
- 流式工具 index 必须为非负整数；同一 index 的 ID/名称不可改变。无序到达的不同 index 和省略/为 null 的后续元数据仍可正确续接。
- 编辑器保留异步请求快照，旧检测/保存结果不能覆盖重新打开或已更改的表单；取消仍向上游传播。
