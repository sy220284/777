# 人物预设立绘生成规范

## 目标

人物图集内置预设使用项目生成的人物形象图，不使用官方立绘、官方宣传图、游戏截图或直接下载的网络素材。

首批与当前预设人物保持一致：

- 神里绫华（原神）
- 卡芙卡（崩坏：星穹铁道）
- 赵二（燕云十六声）
- 黎深（恋与深空）

## 统一视觉规范

- 画面：竖版 2:3，人物半身或 3/4 身，主体居中偏上。
- 视觉：高完成度二次元/半写实角色插画，保留角色可识别的发色、发型、气质和代表性服装语言，但不复刻官方立绘构图。
- 场景：简洁、有氛围但不抢人物；保证人物图集卡片裁切后仍清晰。
- 表情：自然、符合人物性格，避免夸张表情包感。
- 禁止：Logo、UI、宣传文案、水印、签名、官方立绘姿势复刻、官方宣传图背景复刻。
- 输出：优先 WebP，建议 1024×1536；人物脸部与上半身区域必须适合 1:1 头像裁切。

## 接入检查

每张图接入前必须确认：

1. 来源为本项目自行生成或制作。
2. 无官方素材拼接、无网络素材直接使用。
3. 文件名与 PersonaPreset 稳定 ID 一致。
4. 画面可正常解码，大小不超过人物立绘上限。
5. 人物预设安装后，portraitPath 指向 App 私有目录副本；用户后续替换图片不影响内置资产。
