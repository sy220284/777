# V5 里程碑研究与防过拟合协议

## 目标

研究目标按奖级逐级推进：四等奖稳定提升 → 三等奖 → 二等奖 → 一等奖。

“历史上出现一次更高奖级”只记为里程碑候选，不直接视为模型有效。模型晋级需要同时证明预测逻辑可复现、时间上因果、参数附近稳定，并在未参与选择的数据上继续成立。

## 固定成本

- 每期开奖固定 2 注。
- 不允许通过增加注数、扩大复式成本或事后补票制造更高奖级。
- 比较模型时成本完全一致。

## 数据分层

1. `seq <= 3446`：研究历史。允许用于滚动训练和因果的在线策略选择，但每个目标期只能读取之前数据。
2. `seq = 3447..3501`：旧独立前向段。由于已经被多轮研究查看，从 V5 起降级为二级确认集，不允许再据此选择参数。
3. `seq >= 3502`（2026105起）：新影子前向段。参数和规则在开奖前冻结；开奖后只记分，不反向改写已经产生的预测。

## 晋级条件

候选模型必须同时通过以下门槛：

1. **奖级里程碑**：最高奖级优于当前主版本，或在相同最高奖级下显著增加高红球命中事件（优先比较 6红、5+红、4+红）。
2. **因果性**：任何特征、模型权重、门控、组合方式只能读取目标期开奖前的数据。
3. **邻域稳定**：若存在连续参数，相邻参数必须呈现平台或同方向改善；孤立单点最优判为高风险。
4. **时间稳定**：研究历史至少切成4个连续时间块，多数时间块不得相对基线系统性恶化；高奖不能全部来自一个极窄时期。
5. **二级确认**：3447..3501不得出现明显结构性崩溃。该段不用于选参数。
6. **新前向确认**：2026105之后持续记录真实预测；只有积累新的未触碰样本后，才允许使用“稳定有效”表述。
7. **多重尝试控制**：每轮预先限定候选族和参数网格；失败路线记录并保留，禁止删除失败结果后只展示最好一次。
8. **随机对照**：高奖候选必须与同成本随机组合、时间打乱或标签置换对照，确认结果不是容易由大量尝试撞出的极值。

## 模型逻辑约束

V5 优先采用可解释的两层结构：

- **号码层**：对33个红球形成逐期、因果的相对排序或概率；目标是提高真实6红进入候选区域的机会。
- **组合层**：在固定2注成本下，把候选信息压缩成两张6红票；可使用核心号共享、边缘号分叉、历史联合关系，但共享强度必须由过去数据决定。

蓝球独立评估，不允许用少数5红事件的实际蓝球进行事后定向调参。

## 结果记录

每次实验至少记录：

- 完整候选定义与参数范围；
- 代码提交号；
- 全期、4个连续时间块、3447..3501二级确认段；
- 每期最高红球命中、最高奖级、逐票奖级；
- 4+红、5+红、6红出现次数；
- 固定成本回报；
- 与当前主版本和同成本随机基线对照；
- 失败原因与是否淘汰。

任何未通过上述门槛的结果保持在 `research` 状态，不进入主版本。
