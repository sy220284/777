## 判断

1. 固定共享核心会显著损失覆盖面；共享越强，平均与高阶红球命中总体越差。
2. `core=4` 在新增55期出现1次五等奖，但该段没有4+红事件，属于蓝球/3红组合形成的奖级变化，不是红球预测突破。
3. 自适应核心选择未能恢复V4.5的3次5红事件，说明仅按过去4+/5+事件率切核心规模不足以描述组合状态。
4. 当前最值得研究的是V4.5自身已有的3次单票5红事件：确认漏掉第6红的当期排序位置、蓝球排名与候选池全6覆盖情况，再决定下一代模型改号码层还是组合层。

结论：本路线不进入主版本，不继续围绕固定核心规模调参数。
