# 朝夕 E8.17 独立界面

本包通过 `UiApplicationScenePack` 接入，内部仅依赖 `:ui-contract` 和 `:ui-host`，不依赖 App 或旧 V6。App 的 `ZhaoxiApplicationRoot` 注入现有 Feature Ports，宿主统一校验目录、能力和导航。

## 当前接入

- 编译图、75 个非宿主场景的声明与 Renderer 对照、完整准入已有自动测试。
- 43 个独立图标由原始 SVG（另含一份 sprite）生成原生矢量资源；保留几何、描边与实心点。运行时不再手动解析 SVG，设备测试逐个加载并检查实际绘制。
- 模型配置与选择、账户、性能、价格、用量、记忆及会话存储使用各自 Owner 接口。
- Chat/Work 草稿和附件来自宿主持久化端口；拒收、失败、结果未知保留输入，受理后仅清理本次提交内容。
- 消息操作绑定所选消息及原会话身份；历史分页与阅读位置通过既有端口处理。
- 渐进式回复采用原会话消息流：阶段消息与最终答案共享正文排版，不重复显示固定的「工作任务」卡或逐段「阶段进展」标题。\`work-live:<messageId>\` 是 Work Owner 的只读事件投影，保留在原文档与审计记录中，但不自动插入 Chat/Work 时间线；其他交互文档、表格、媒体结果继续随消息显示。
- 执行中状态、停止、审批和提问依旧由真实 Work Owner 控制；界面不虚构进度百分比和已验收结论。
- 群成员、群公告、回复建议、人物创建/编辑/预设/导入导出、故事选择和画像操作连接真实接口。
- 媒体使用真实配置、会话结果与受理回执，保存/分享由宿主提供系统入口；重生成显式确认调用并校验原凭据。
- 槽位内容嵌入页面；宿主只允许页面和浮层入导航栈。转场只保留当前一棵活动内容树。

## 补充设备验收

`ZhaoxiAcceptanceAndroidTest` 复用生产装配与真实本地 Owner：75 场景渲染、15 页浅色/深色/130% 字号截图，另检验字号跨重建、开关语义及模型本地保存。截图由 Android 16/17 CI Artifact 提供。渲染覆盖包含空消息/空媒体状态，不代表外部业务成功态或所有动作端到端通过；结果以对应 Head 的 CI 为准。

## 验证边界

场景目录和准入证明结构一致，不证明每个动作已端到端验收。当前修改仍需以 PR #740 最新 Head 的 JVM、ARM64/x86 和 Android 16/17 结果为准；保持 Draft，不授权合并或发布。真实账户、付费媒体、真机视觉、TalkBack 和长时间运行尚需专项验收，不以代理端口或静态检查冒充。
