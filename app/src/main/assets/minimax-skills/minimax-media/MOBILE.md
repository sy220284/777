# 手机端 MiniMax 多媒体 API
使用内置 Node 运行 MiniMax CLI，与外部 API 通信；音视频生成由服务端完成。
先读取工具说明，复用工作区已配置的 mmx-cli；未安装时在项目目录用 npm 安装，并通过 Node 或项目本地入口运行，不全局安装，不修改系统 PATH。
按需读取 upstream 中 CLI 命令参考。只使用当前凭据具有权限的图像、视频、语音和音乐命令；M Plan 订阅密钥并不自动具有媒体 API 权限。
凭据由用户在受控位置配置。不得要求把密钥发进聊天，不将密钥放进命令参数、日志或产物。
异步生成保留服务端任务 ID，查询真实完成状态后再下载到工作区。用户取消时停止轮询，支持取消接口时调用服务端取消。
交付原始媒体文件，通过 Android 的文件打开/分享体验播放；不调用 ffmpeg、mpv、afplay 或桌面播放器，不提供本机转码、拼接或格式转换能力。
