# 手机端 MiniMax 多媒体能力
优先使用 777 原生多模态底座和媒体创作任务记录；不要默认调用 Node 或 mmx-cli。
MiniMax 图片：Work 模式调用 media_image_options 查当前真实已配置的创作服务，再由用户明确选择 API 账户，经原有审批使用 media_image_create；用 media_image_status 查询任务，等待媒体结果实际保存后交付。聊天模式使用其当前已实现的图像功能，不能凭技能文档假定任意模型都支持。
视频、配音、转写：先核实现有媒体创作界面的原生支持及权限，沿原有任务状态与成果保存路径执行，不复制第二套 SDK。音乐目前不等于语音合成，必须单独核实执行入口。
当确需 CLI 独有功能时，先通过环境工具确认本机存在可用 Node 和本地 mmx-cli，并取得用户同意；CLI 命令详见 CLI.md。不得因文档写有 CLI 就自动安装 Node/npm 包、修改 PATH 或执行未授权联网下载。
MiniMax M Plan 订阅权限与媒体 API 权限不同，不能借用聊天凭据向媒体 API 发请求。密钥只由应用已有受控凭据系统管理，不能写入聊天、命令、日志或成果文件。
生成、保存和交付均使用真实服务状态；未完成、结果未知或写盘失败时不得宣称成功，也不得静默重新提交付费生成。
