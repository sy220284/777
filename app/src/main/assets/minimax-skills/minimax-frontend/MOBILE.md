# 手机端前端设计
1. 读取工作区工具说明，使用现有文件和 Node 工具；项目依赖安装在项目目录，不改系统 PATH。
2. 使用 upstream/references 中设计、排版、动效资料。交付能直接打开的 HTML/CSS/JavaScript；单页任务优先完整 HTML，资源使用相对路径或内嵌。
3. 用 777 工作区文件预览打开 HTML。先检查手机窄屏、触摸操作、文字溢出和按钮可点击性；需要截图时使用当前实际可用的设备工具。
4. React 项目按现有 npm 构建脚本执行，并交付可预览的构建结果。没有桌面浏览器时不要尝试安装 Playwright、Chromium 或 Puppeteer；在手机预览检查。
5. 图片采用用户素材、现有生成工具或已配置 API；生成实际成功前使用明确的占位，不虚构素材。
