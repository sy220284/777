# 手机端 MiniMax 音乐创作
先核对用户需要的音乐时长、曲风、歌词、人声及用途，形成音乐生成参数。语音 TTS 与歌曲生成是不同功能，不能将配音工具冒充音乐生成。
优先检查 777 当前注册的原生音乐生成 API 工具；未接通时仅在用户主动授权且本机确认已具备本地 Node/mmx-cli 时使用 CLI.md 的对应音乐命令，不自动安装或修改设备环境。CLI 只作可选补充路径。
只使用用户明确配置且具有媒体 API 权限的账户；不能把 M Plan 的聊天订阅等同于媒体额度。密钥不得进入聊天、命令参数、日志和导出产物。
实际生成后保存服务端任务标识并检查成功状态，下载可用音频到工作区后通过手机文件打开/分享；遇到状态未知不得重复收费提交。没有执行条件时只交付创作方案和明确缺失能力。
