# 手机端歌单与封面
依据用户提供的音乐、偏好、真实来源及工作区已有成果规划歌单；不读取桌面音乐应用、系统音乐数据库或其他应用的私有目录。
先安排主题、曲风、顺序、歌词语言与播放节奏。歌单策划本身不需要付费媒体调用；创建新歌和封面需要用户明确要求。
封面优先使用 777 的原生图片创作工具与已配置的媒体 API 账户，通过真实回执与素材档案确认成果。歌曲生成需单独核实原生音乐工具，未接通时只有用户许可且本地 CLI 真正可用才参考 CLI.md，不自动安装运行环境。
可根据真实文件生成 playlist.html 和清单 JSON，并通过 777 已有预览/分享功能交付；缺少文件时只提供纯文字歌单，不伪造音频或封面，不调用桌面播放器与 ffmpeg。
