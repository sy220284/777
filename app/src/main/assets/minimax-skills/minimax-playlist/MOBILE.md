# 手机端歌单与封面
从用户明确提供的歌曲、歌单文件、偏好和本工作区已有生成反馈分析口味；不访问桌面音乐应用、系统音乐数据库或其他应用私有目录。
先给出歌单主题、曲风、顺序和歌词语言。需要生成新歌或封面时，用已配置的 MiniMax CLI 调用服务端，使用内置 Node 与项目本地 CLI，命令参考见 CLI.md；凭据由用户在受控位置配置，不能写进聊天、命令或日志。
使用实际完成的音频及封面，创建带相对资源链接的 playlist.html 和清单 JSON；通过 777 HTML 文件预览查看封面和选择歌曲，音频使用手机文件打开或页面实际支持的播放控件。
没有媒体 API 权限时只交付用户要求的歌单规划，不能假装生成过歌曲；不调用 mpv、ffplay、afplay 或 ffmpeg。
